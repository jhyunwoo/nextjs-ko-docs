The `'use client'` 지시문은 **클라이언트 측**에서 렌더링될 구성 요소에 대한 진입점을 선언하며 상태 관리, 이벤트 처리 및 브라우저 API에 대한 액세스와 같은 클라이언트 측 JavaScript 기능이 필요한 대화형 사용자 인터페이스(UI)를 생성할 때 사용해야 합니다. 이것은 React 기능입니다.

> **알아두면 좋은 점:**
>
> 클라이언트 구성 요소가 포함된 모든 파일에 `'use client'` 지시어를 추가할 필요는 없습니다. 서버 구성 요소 내에서 직접 렌더링하려는 구성 요소가 있는 파일에만 추가하면 됩니다. `'use client'` 지시어는 클라이언트-서버 [경계](https://nextjs.org/docs/app/building-your-application/rendering#network-boundary)를 정의하며, 이러한 파일에서 내보낸 구성 요소는 클라이언트에 대한 진입점 역할을 합니다.

## 사용법

클라이언트 구성 요소에 대한 진입점을 선언하려면 가져오기 전에 `'use client'` 지시문을 추가하세요.**at the top of the file**, before any imports:

```tsx filename="app/components/counter.tsx" highlight={1} switcher
'use client'

import { useState } from 'react'

export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  )
}
```

```jsx filename="app/components/counter.js" highlight={1} switcher
'use client'

import { useState } from 'react'

export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  )
}
```

When using the `'use client'` 지시문을 사용할 때 클라이언트 구성 요소의 props는 [직렬화](https://react.dev/reference/rsc/use-client#serializable-types)되어야 합니다. 이는 props가 서버에서 클라이언트로 데이터를 보낼 때 React가 직렬화할 수 있는 형식이어야 함을 의미합니다.

```tsx filename="app/components/counter.tsx" highlight={4} switcher
'use client'

export default function Counter({
  onClick /* ❌ Function is not serializable */,
}) {
  return (
    <div>
      <button onClick={onClick}>Increment</button>
    </div>
  )
}
```

```jsx filename="app/components/counter.js" highlight={4} switcher
'use client'

export default function Counter({
  onClick /* ❌ Function is not serializable */,
}) {
  return (
    <div>
      <button onClick={onClick}>Increment</button>
    </div>
  )
}
```

## 서버 구성 요소 내에 클라이언트 구성 요소 중첩

서버와 클라이언트 구성 요소를 결합하면 성능이 뛰어나고 대화형인 응용 프로그램을 구축할 수 있습니다.

1. **서버 구성 요소**: 정적 콘텐츠, 데이터 가져오기 및 SEO 친화적인 요소에 사용됩니다.
1. **클라이언트 구성 요소**: 상태, 효과 또는 브라우저 API가 필요한 대화형 요소에 사용합니다.
1. **구성요소 구성**: 서버와 클라이언트 로직을 명확하게 분리하기 위해 필요에 따라 서버 구성요소 내에 클라이언트 구성요소를 중첩합니다.

다음 예에서는:

- `Header`은 정적 콘텐츠를 처리하는 서버 구성 요소입니다.
- `Counter`는 페이지 내에서 상호 작용을 활성화하는 클라이언트 구성 요소입니다.

```tsx filename="app/page.tsx" highlight={2,8} switcher
import Header from './header'
import Counter from './counter' // This is a Client Component

export default function Page() {
  return (
    <div>
      <Header />
      <Counter />
    </div>
  )
}
```

```jsx filename="app/page.js" highlight={2,8} switcher
import Header from './header'
import Counter from './counter' // This is a Client Component

export default function Page() {
  return (
    <div>
      <Header />
      <Counter />
    </div>
  )
}
```
