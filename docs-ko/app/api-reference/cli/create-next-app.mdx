`create-next-app` CLI를 사용하면 기본 템플릿 또는 공개 GitHub 저장소의 [예](https://github.com/vercel/next.js/tree/canary/examples)를 사용하여 새로운 Next.js 애플리케이션을 생성할 수 있습니다. Next.js를 시작하는 가장 쉬운 방법입니다.

기본 사용법:

```bash filename="Terminal"
npx create-next-app@latest [project-name] [options]
```

## 참조

다음 옵션을 사용할 수 있습니다.| 옵션 | 설명 |
| -------------------------- | -------------------------------------------------------- |
| `-h` 또는 `--help` | 사용 가능한 모든 옵션 표시 |
| `-v` 또는 `--version` | 버전 번호 출력 |
| `--no-*` | 기본 옵션을 무효화합니다. 예: `--no-ts` |
| `--ts` 또는 `--typescript` | TypeScript 프로젝트로 초기화(기본값) |
| `--js` 또는 `--javascript` | JavaScript 프로젝트로 초기화 |
| `--tailwind` | Tailwind CSS 구성으로 초기화(기본값) |
| `--react-compiler` | React 컴파일러를 사용하여 초기화 |
| `--eslint` | ESLint 구성으로 초기화 |
| `--biome` | Biome 구성으로 초기화 |
| `--no-linter` | 린터 구성 건너뛰기 |
| `--app` | 앱 라우터 프로젝트로 초기화 |
| `--api` | 경로 핸들러만 사용하여 프로젝트 초기화 |
| `--src-dir` | `src/` 디렉터리 내부에서 초기화 |
| `--turbopack` | 생성된 package.json에서 Turbopack 강제 활성화(기본적으로 활성화됨) |
| `--webpack` | 생성된 package.json에서 Webpack를 강제 활성화 |
| `--import-alias <alias-to-configure>` | 사용할 가져오기 별칭 지정(기본값 "@/\*") |
| `--empty` | 빈 프로젝트 초기화 |
| `--use-npm` | npm를 사용하여 애플리케이션을 부트스트랩하도록 CLI에 명시적으로 지시 |

| `-e` 또는 `--example [name] [github-url]` | |를 사용하여 앱을 부트스트랩하는 예
| `--example-path <path-to-example>` | 예제의 경로를 별도로 지정 |

### 기본 템플릿 사용

기본 템플릿을 사용하여 새 앱을 만들려면 터미널에서 다음 명령을 실행하세요.

```bash filename="Terminal"
npx create-next-app@latest
```

설치 시 다음 메시지가 표시됩니다.

```txt filename="Terminal"
What is your project named? my-app
Would you like to use the recommended Next.js defaults?
    Yes, use recommended defaults - TypeScript, ESLint, Tailwind CSS, App Router, Turbopack
    No, reuse previous settings
    No, customize settings - Choose your own preferences
```

`customize settings`을 선택하면 다음 메시지가 표시됩니다.

```txt filename="Terminal"
Would you like to use TypeScript? No / Yes
Which linter would you like to use? ESLint / Biome / None
Would you like to use React Compiler? No / Yes
Would you like to use Tailwind CSS? No / Yes
Would you like your code inside a `src/` directory? No / Yes
Would you like to use App Router? (recommended) No / Yes
Would you like to customize the import alias (`@/*` by default)? No / Yes
What import alias would you like configured? @/*
```

프롬프트 후에 `create-next-app`는 프로젝트 이름으로 폴더를 생성하고 필요한 종속성을 설치합니다.

### 린터 옵션

**ESLint**: 전통적이고 가장 인기 있는 JavaScript 린터입니다. `@next/eslint-plugin-next`의 Next.js 관련 규칙을 포함합니다.

**Biome**: ESLint 및 Prettier의 기능을 결합한 빠르고 현대적인 린터 및 포맷터입니다. 최적의 성능을 위해 내장된 Next.js 및 React 도메인 지원을 포함합니다.

**없음**: Linter 구성을 완전히 건너뜁니다. 나중에 언제든지 린터를 추가할 수 있습니다.

프롬프트에 응답하면 선택한 구성으로 새 프로젝트가 생성됩니다.

### 공식 Next.js 예시를 통해

공식 Next.js 예제를 사용하여 새 앱을 만들려면 `--example` 플래그를 사용하세요. 예를 들면:

```bash filename="Terminal"
npx create-next-app@latest --example [example-name] [your-project-name]
```

[Next.js 저장소](https://github.com/vercel/next.js/tree/canary/examples)에서 설정 지침과 함께 사용 가능한 모든 예제 목록을 볼 수 있습니다.

### 공개 GitHub 예를 사용하면

공개 GitHub 예제를 사용하여 새 앱을 만들려면 GitHub 저장소의 URL와 함께 `--example` 옵션을 사용하세요. 예를 들면:

```bash filename="Terminal"
npx create-next-app@latest --example "https://github.com/.../" [your-project-name]
```
