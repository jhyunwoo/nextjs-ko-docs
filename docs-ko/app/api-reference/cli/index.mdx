title: CLI
description: Next.js 명령줄 인터페이스(CLI) 도구에 대한 API 참조입니다.
---

Next.js에는 **두 가지** 명령줄 인터페이스(CLI) 도구가 함께 제공됩니다.

- **`create-next-app`**: 기본 템플릿 또는 공개 GitHub 저장소의 [예](https://github.com/vercel/next.js/tree/canary/examples)를 사용하여 새로운 Next.js 애플리케이션을 빠르게 생성합니다.
- **`next`**: Next.js 개발 서버를 실행하고 애플리케이션을 빌드하는 등의 작업을 수행합니다.
