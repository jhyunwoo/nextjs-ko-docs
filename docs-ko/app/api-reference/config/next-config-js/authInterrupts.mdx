The `authInterrupts` 구성 옵션을 사용하면 애플리케이션에서 [`forbidden`](../../functions/forbidden.mdx) 및 [`unauthorized`](../../functions/unauthorized.mdx) API를 사용할 수 있습니다. 이러한 기능은 실험적이지만 이를 사용하려면 `authInterrupts` 파일에서 `next.config.js` 옵션을 활성화해야 합니다.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    authInterrupts: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
module.exports = {
  experimental: {
    authInterrupts: true,
  },
}
```
