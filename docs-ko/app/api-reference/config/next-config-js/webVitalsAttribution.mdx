웹 바이탈과 관련된 문제를 디버깅할 때 문제의 원인을 정확히 찾아낼 수 있으면 도움이 되는 경우가 많습니다.
예를 들어 CLS(누적 레이아웃 변경)의 경우 가장 큰 단일 레이아웃 변경이 발생할 때 이동된 첫 번째 요소를 알고 싶을 수 있습니다.
또는 LCP(Contentful Paint)의 경우 페이지의 LCP에 해당하는 요소를 식별할 수 있습니다.
LCP 요소가 이미지인 경우 이미지 리소스의 URL를 알면 최적화해야 하는 자산을 찾는 데 도움이 될 수 있습니다.

Web Vitals 점수에 가장 큰 기여를 하는 요소, 즉 [속성](https://github.com/GoogleChrome/web-vitals/blob/4ca38ae64b8d1e899028c692f94d4c56acfc996c/README.md#attribution)을 찾아냅니다.
이를 통해 [PerformanceEventTiming](https://developer.mozilla.org/docs/Web/API/PerformanceEventTiming), [PerformanceNavigationTiming](https://developer.mozilla.org/docs/Web/API/PerformanceNavigationTiming) 및 [PerformanceResourceTiming](https://developer.mozilla.org/docs/Web/API/PerformanceResourceTiming)에 대한 항목과 같은 더 자세한 정보를 얻을 수 있습니다.

속성은 Next.js에서 기본적으로 비활성화되어 있지만 `next.config.js`에서 다음을 지정하여 **측정항목별로** 활성화할 수 있습니다.

```js filename="next.config.js"
module.exports = {
  experimental: {
    webVitalsAttribution: ['CLS', 'LCP'],
  },
}
```

유효한 속성 값은 [`web-vitals`](https://github.com/vercel/next.js/blob/442378d21dd56d6e769863eb8c2cb521a463a2e0/packages/next/shared/lib/utils.ts#L43) 유형에 지정된 모든 `NextWebVitalsMetric` 지표입니다.
