> **알아두면 좋은 정보**: 이 옵션은 Next.js 13.4부터 **더 이상 필요하지 않습니다**. 이제 앱 라우터가 안정적입니다.

앱 라우터([`app` 디렉터리](../../../index.mdx))는 [레이아웃](../../file-conventions/layout.mdx), [서버 구성 요소](../../../getting-started/server-and-client-components.mdx), [스트리밍](../../file-conventions/loading.mdx) 및 \[같은 위치에 있는 데이터]에 대한 지원을 활성화합니다. 가져오는 중]\(../../../getting-started/fetching-data.mdx).[colocated data fetching](../../../getting-started/fetching-data.mdx).

Using the `app` 디렉터리를 사용하면 [React 엄격 모드](https://react.dev/reference/react/StrictMode)가 자동으로 활성화됩니다. [incrementally adopt `app`](../../../guides/migrating/app-router-migration.mdx#migrating-from-pages-to-app)하는 방법을 알아보세요.
