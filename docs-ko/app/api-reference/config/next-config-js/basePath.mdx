description: 도메인의 하위 경로 아래에 Next.js 애플리케이션을 배포하려면 'basePath'를 사용하세요.
---

도메인의 하위 경로 아래에 Next.js 애플리케이션을 배포하려면 `basePath` 구성 옵션을 사용할 수 있습니다.

`basePath`을 사용하면 애플리케이션에 대한 경로 접두어를 설정할 수 있습니다. 예를 들어, `/docs`(빈 문자열, 기본값) 대신 `''`을 사용하려면 `next.config.js`을 열고 `basePath` 구성을 추가합니다.

```js filename="next.config.js"
module.exports = {
  basePath: '/docs',
}
```

> **알아두면 좋은 정보**: 이 값은 빌드 시 설정해야 하며 값이 클라이언트 측 번들에 인라인되므로 다시 빌드하지 않고 변경할 수 없습니다.

### 링크

When linking to other pages using `next/link` 및 `next/router`을 사용하여 다른 페이지에 링크하면 `basePath`이 자동으로 적용됩니다.

예를 들어, `/about`이 `/docs/about`로 설정된 경우 `basePath`을 사용하면 자동으로 `/docs`이 됩니다.

```js
export default function HomePage() {
  return (
    <>
      <Link href="/about">About Page</Link>
    </>
  )
}
```

출력 HTML:

```html
<a href="/docs/about">About Page</a>
```

이렇게 하면 `basePath` 값을 변경할 때 애플리케이션의 모든 링크를 변경할 필요가 없습니다.

### 이미지

When using the [`next/image`](../../components/image.mdx) 구성요소를 사용하는 경우 `basePath` 앞에 `src`를 추가해야 합니다.

예를 들어 `/docs/me.png`을 사용하면 `basePath`가 `/docs`로 설정된 경우 이미지가 올바르게 제공됩니다.

```jsx
import Image from 'next/image'

function Home() {
  return (
    <>
      <h1>My Homepage</h1>
      <Image
        src="/docs/me.png"
        alt="Picture of the author"
        width={500}
        height={500}
      />
      <p>Welcome to my homepage!</p>
    </>
  )
}

export default Home
```
