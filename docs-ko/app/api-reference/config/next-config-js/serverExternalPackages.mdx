[서버 구성 요소](../../../getting-started/server-and-client-components.mdx) 및 [경로 처리기](../../file-conventions/route.mdx) 내부에서 사용되는 종속성은 Next.js에 의해 자동으로 번들됩니다.

종속성이 Node.js 특정 기능을 사용하는 경우 서버 구성 요소 번들링에서 특정 종속성을 선택 해제하고 기본 Node.js `require`을 사용하도록 선택할 수 있습니다.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ['@acme/ui'],
}

module.exports = nextConfig
```

Next.js에는 현재 호환성을 위해 작업 중이며 자동으로 제외되는 [인기 패키지의 간단한 목록](https://github.com/vercel/next.js/blob/canary/packages/next/src/lib/server-external-packages.jsonc)이 포함되어 있습니다.
