title: 타이프스크립트
description: 프로덕션 빌드 중에 Next.js가 TypeScript 오류를 처리하는 방법을 구성하고 사용자 정의 tsconfig 파일을 지정합니다.
---

`typescript`의 `next.config.js` 옵션을 사용하여 TypeScript 동작을 구성합니다.

```js filename="next.config.js"
module.exports = {
  typescript: {
    ignoreBuildErrors: false,
    tsconfigPath: 'tsconfig.json',
  },
}
```

## 옵션

| 옵션 | 유형 | 기본값 | 설명 |
| ------ | --------- | ----------------- | ---------------------------------------------------------------- |
| `ignoreBuildErrors` | `boolean` | `false` | TypeScript 오류가 발생하더라도 프로덕션 빌드가 완료되도록 허용합니다. |
| `tsconfigPath` | `string` | `'tsconfig.json'` | 사용자 정의 `tsconfig.json` 파일의 경로입니다.                           |

## `ignoreBuildErrors`

프로젝트에 TypeScript 오류가 있으면 Next.js가 **프로덕션 빌드**(`next build`)에 실패합니다.

애플리케이션에 오류가 있는 경우에도 Next.js가 프로덕션 코드를 위험하게 생성하도록 하려면 내장된 유형 검사 단계를 비활성화할 수 있습니다.

비활성화된 경우 빌드 또는 배포 프로세스의 일부로 유형 검사를 실행하고 있는지 확인하세요. 그렇지 않으면 매우 위험할 수 있습니다.

```js filename="next.config.js"
module.exports = {
  typescript: {
    // !! WARN !!
    // Dangerously allow production builds to successfully complete even if
    // your project has type errors.
    // !! WARN !!
    ignoreBuildErrors: true,
  },
}
```

## `tsconfigPath`

빌드 또는 도구에 다른 TypeScript 구성 파일을 사용합니다.

```js filename="next.config.js"
module.exports = {
  typescript: {
    tsconfigPath: 'tsconfig.build.json',
  },
}
```

자세한 내용은 [TypeScript 구성](../typescript.mdx#custom-tsconfig-path) 페이지를 참조하세요.
