URL 가져오기는 로컬 디스크 대신 외부 서버에서 직접 모듈을 가져올 수 있는 실험적 기능입니다.

> **경고**: 신뢰할 수 있는 도메인만 사용하여 컴퓨터에서 다운로드하고 실행하세요. 기능이 안정적인 것으로 표시될 때까지 신중하고 주의를 기울이십시오.

선택하려면 `next.config.js` 내에 허용되는 URL 접두사를 추가하세요.

```js filename="next.config.js"
module.exports = {
  experimental: {
    urlImports: ['https://example.com/assets/', 'https://cdn.skypack.dev'],
  },
}
```

그런 다음 URL에서 직접 모듈을 가져올 수 있습니다.

```js
import { a, b, c } from 'https://example.com/assets/some/module.js'
```

URL 가져오기는 일반 패키지 가져오기를 사용할 수 있는 모든 곳에서 사용할 수 있습니다.

## 보안 모델

이 기능은 **보안을 최우선으로** 설계되었습니다. 시작하기 위해 URL 가져오기를 허용하는 도메인을 명시적으로 허용하도록 강제하는 실험적 플래그를 추가했습니다. 우리는 [Edge 런타임](../../edge.mdx)을 사용하여 브라우저 샌드박스에서 실행되는 URL 가져오기를 제한하여 이 문제를 더욱 발전시키기 위해 노력하고 있습니다.

## 잠금 파일

URL 가져오기를 사용할 때 Next.js는 잠금 파일과 가져온 자산을 포함하는 `next.lock` 디렉터리를 생성합니다.
이 디렉터리는 **Git에 커밋되어야** 하며 `.gitignore`에서 무시되지 않습니다.

- `next dev`을 실행할 때 Next.js는 새로 발견된 모든 URL 가져오기를 다운로드하여 잠금 파일에 추가합니다.
- `next build`을 실행할 때 Next.js는 잠금 파일만 사용하여 프로덕션용 애플리케이션을 빌드합니다.

일반적으로 네트워크 요청이 필요하지 않으며 오래된 잠금 파일로 인해 빌드가 실패합니다.
한 가지 예외는 `Cache-Control: no-cache`로 응답하는 리소스입니다.
이러한 리소스는 잠금 파일에 `no-cache` 항목을 가지며 항상 각 빌드의 네트워크에서 가져옵니다.

## 예

### 스카이팩

```js
import confetti from 'https://cdn.skypack.dev/canvas-confetti'
import { useEffect } from 'react'

export default () => {
  useEffect(() => {
    confetti()
  })
  return <p>Hello</p>
}
```

### 정적 이미지 가져오기

```js
import Image from 'next/image'
import logo from 'https://example.com/assets/logo.png'

export default () => (
  <div>
    <Image src={logo} placeholder="blur" />
  </div>
)
```

CSS의 ### URL

```css
.className {
  background: url('https://example.com/assets/hero.jpg');
}
```

### 자산 수입

```js
const logo = new URL('https://example.com/assets/file.txt', import.meta.url)

console.log(logo.pathname)

// prints "/_next/static/media/file.a9727b5d.txt"
```
