  방법에 대해 자세히 알아보세요.
---

18 이전의 Node.js 버전에서 Next.js는 `fetch()`을 [undici](../../../../architecture/supported-browsers.mdx#polyfills)로 자동으로 폴리필하고 기본적으로 [HTTP 연결 유지](https://developer.mozilla.org/docs/Web/HTTP/Headers/Keep-Alive)를 활성화합니다.

서버 측의 모든 `fetch()` 호출에 대해 HTTP 연결 유지를 비활성화하려면 `next.config.js`을 열고 `httpAgentOptions` 구성을 추가하세요.

```js filename="next.config.js"
module.exports = {
  httpAgentOptions: {
    keepAlive: false,
  },
}
```
