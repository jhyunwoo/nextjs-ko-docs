---
title: allowedDev출처
description: 개발 서버를 요청할 수 있는 추가 원본을 구성하려면 `allowedDevOrigins`를 사용하세요.
---

Next.js는 개발 중에 원본 간 요청을 자동으로 차단하지 않지만, 개발 모드에서 사용할 수 있는 내부 자산/엔드포인트에 대한 무단 요청을 방지하기 위해 Next.js의 향후 주요 버전에서는 기본적으로 차단합니다.

서버가 초기화된 호스트 이름(기본적으로 `localhost`) 이외의 원본으로부터의 요청을 허용하도록 Next.js 애플리케이션을 구성하려면 `allowedDevOrigins` 구성 옵션을 사용할 수 있습니다.

`allowedDevOrigins`을 사용하면 개발 모드에서 사용할 수 있는 추가 원본을 설정할 수 있습니다. 예를 들어 `local-origin.dev`만 사용하는 대신 `localhost`을 사용하려면 `next.config.js`을 열고 `allowedDevOrigins` 구성을 추가하세요.

```js filename="next.config.js"
module.exports = {
  allowedDevOrigins: ['local-origin.dev', '*.local-origin.dev'],
}
```
