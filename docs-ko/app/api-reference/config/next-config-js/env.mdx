> Since the release of [Next.js 9.4](https://nextjs.org/blog/next-9-4) 릴리스 이후 이제 [환경 변수 추가](../../../guides/environment-variables.mdx)에 대한 보다 직관적이고 인체공학적인 환경을 갖게 되었습니다. 한번 시도해 보세요!

> **알아두면 좋은 정보**: 이 방법으로 지정된 환경 변수는 **항상** JavaScript 번들에 포함되며, 환경 변수 이름 앞에 `NEXT_PUBLIC_`을 붙이면 [환경 또는 .env 파일을 통해](../../../guides/environment-variables.mdx) 지정할 때만 효과가 있습니다.

JavaScript 번들에 환경 변수를 추가하려면 `next.config.js`을 열고 `env` 구성을 추가하세요.

```js filename="next.config.js"
module.exports = {
  env: {
    customKey: 'my-value',
  },
}
```

이제 코드에서 `process.env.customKey`에 액세스할 수 있습니다. 예를 들면:

```jsx
function Page() {
  return <h1>The value of customKey is: {process.env.customKey}</h1>
}

export default Page
```

Next.js는 빌드 시 `process.env.customKey`을 `'my-value'`로 대체합니다. `process.env` 변수의 구조를 해제하려는 시도는 웹팩 [DefinePlugin](https://webpack.js.org/plugins/define-plugin/)의 특성으로 인해 작동하지 않습니다.

예를 들어 다음 줄은 다음과 같습니다.

```jsx
return <h1>The value of customKey is: {process.env.customKey}</h1>
```

결국은 다음과 같습니다.

```jsx
return <h1>The value of customKey is: {'my-value'}</h1>
```
