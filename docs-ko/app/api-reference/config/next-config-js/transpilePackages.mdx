Next.js는 로컬 패키지(예: monorepos) 또는 외부 종속성(`node_modules`)의 종속성을 자동으로 트랜스파일하고 번들링할 수 있습니다. 이는 `next-transpile-modules` 패키지를 대체합니다.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  transpilePackages: ['package-name'],
}

module.exports = nextConfig
```

## 버전 기록

| 버전 | 변경사항 |
| --------- | -------------------------- |
| `v13.0.0` | `transpilePackages`이 추가되었습니다. |
