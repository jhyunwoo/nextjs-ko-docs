Next.js 애플리케이션에서 서버 작업 동작을 구성하기 위한 옵션입니다.

## `allowedOrigins`

서버 작업을 호출할 수 있는 추가 안전한 원본 도메인 목록입니다. Next.js는 서버 작업 요청의 원본을 호스트 도메인과 비교하여 일치하는지 확인하여 CSRF 공격을 방지합니다. 제공되지 않으면 동일한 출처만 허용됩니다.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */

module.exports = {
  experimental: {
    serverActions: {
      allowedOrigins: ['my-proxy.com', '*.my-proxy.com'],
    },
  },
}
```

## `bodySizeLimit`

기본적으로 서버 작업으로 전송되는 요청 본문의 최대 크기는 1MB입니다. 이는 대량의 데이터를 구문 분석하는 데 과도한 서버 리소스가 소모되는 것과 잠재적인 DDoS 공격을 방지하기 위한 것입니다.

그러나 `serverActions.bodySizeLimit` 옵션을 사용하여 이 제한을 구성할 수 있습니다. 바이트 수 또는 바이트가 지원하는 문자열 형식(예: `1000`, `'500kb'` 또는 `'3mb'`)을 사용할 수 있습니다.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */

module.exports = {
  experimental: {
    serverActions: {
      bodySizeLimit: '2mb',
    },
  },
}
```

## 서버 작업 활성화(v13)

서버 작업은 Next.js 14에서 안정적인 기능이 되었으며 기본적으로 활성화되어 있습니다. 그러나 이전 버전의 Next.js를 사용하는 경우 `experimental.serverActions`을 `true`로 설정하여 활성화할 수 있습니다.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const config = {
  experimental: {
    serverActions: true,
  },
}

module.exports = config
```
