---
title: distDir
description: 기본 .next 디렉터리 대신 사용할 사용자 지정 빌드 디렉터리를 설정합니다.
---

You can specify a name to use for a custom build directory to use instead of `.next` 대신 사용할 사용자 정의 빌드 디렉터리에 사용할 이름을 지정할 수 있습니다.

Open `next.config.js`을 열고 `distDir` 구성을 추가합니다.

```js filename="next.config.js"
module.exports = {
  distDir: 'build',
}
```

이제 `next build`을 실행하면 Next.js는 기본 `build` 폴더 대신 `.next`을 사용합니다.

> `distDir` 프로젝트 디렉터리를 벗어나면 **안 됩니다**. 예를 들어, `../build`은 **잘못된** 디렉터리입니다.
