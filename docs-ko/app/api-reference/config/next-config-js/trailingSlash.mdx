---
title: 후행 슬래시
description: 후행 슬래시 유무에 관계없이 해결되도록 Next.js 페이지를 구성합니다.
---

기본적으로 Next.js는 후행 슬래시가 있는 URL를 후행 슬래시가 없는 URL로 리디렉션합니다. 예를 들어 `/about/`은 `/about`로 리디렉션됩니다. 후행 슬래시가 없는 URL가 후행 슬래시가 있는 해당 URL로 리디렉션되는 반대 방향으로 작동하도록 이 동작을 구성할 수 있습니다.

`next.config.js`을 열고 `trailingSlash` 구성을 추가합니다.

```js filename="next.config.js"
module.exports = {
  trailingSlash: true,
}
```

이 옵션을 설정하면 `/about`와 같은 URL가 `/about/`로 리디렉션됩니다.

`trailingSlash: true`을 사용할 때 특정 URL는 예외이며 뒤에 슬래시가 추가되지 않습니다.

- 확장명이 있는 파일과 같은 정적 파일 URL.
- `.well-known/` 아래의 모든 경로.

예를 들어, 다음 URL는 변경되지 않습니다: `/file.txt`, `images/photos/picture.png` 및 `.well-known/subfolder/config.json`.

[`output: "export"`](../../../guides/static-exports.mdx) 구성과 함께 사용하면 `/about` 페이지는 기본 `/about/index.html` 대신 `/about.html`을 출력합니다.

## 버전 기록

| 버전 | 변경사항 |
| -------- | --------- |
| `v9.5.0` | `trailingSlash`이 추가되었습니다. |
