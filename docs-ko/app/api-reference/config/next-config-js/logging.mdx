## 옵션

### 가져오는 중

개발 모드에서 Next.js를 실행할 때 로깅 수준과 전체 URL가 콘솔에 기록되는지 여부를 구성할 수 있습니다.

현재 `logging`은 `fetch` API를 사용하여 데이터를 가져오는 데에만 적용됩니다. Next.js 내부의 다른 로그에는 아직 적용되지 않습니다.

```js filename="next.config.js"
module.exports = {
  logging: {
    fetches: {
      fullUrl: true,
    },
  },
}
```

[서버 구성 요소 HMR 캐시](serverComponentsHmrCache.mdx)에서 복원된 모든 `fetch` 요청은 기본적으로 기록되지 않습니다. 그러나 이는 `logging.fetches.hmrRefreshes`을 `true`로 설정하여 활성화할 수 있습니다.

```js filename="next.config.js"
module.exports = {
  logging: {
    fetches: {
      hmrRefreshes: true,
    },
  },
}
```

### 들어오는 요청

기본적으로 들어오는 모든 요청은 개발 중에 콘솔에 기록됩니다. `incomingRequests` 옵션을 사용하여 무시할 요청을 결정할 수 있습니다.
이는 개발에서만 로그인되므로 이 옵션은 프로덕션 빌드에 영향을 주지 않습니다.

```js filename="next.config.js"
module.exports = {
  logging: {
    incomingRequests: {
      ignore: [/\api\/v1\/health/],
    },
  },
}
```

또는 `incomingRequests`을 `false`로 설정하여 수신 요청 로깅을 비활성화할 수 있습니다.

```js filename="next.config.js"
module.exports = {
  logging: {
    incomingRequests: false,
  },
}
```

### 로깅 비활성화

또한 `logging`을 `false`로 설정하여 개발 로깅을 비활성화할 수 있습니다.

```js filename="next.config.js"
module.exports = {
  logging: false,
}
```
