---
title: 반응컴파일러
description: React Compiler를 활성화하여 구성 요소 렌더링을 자동으로 최적화합니다.
---

Next.js에는 구성 요소 렌더링을 자동으로 최적화하여 성능을 향상시키도록 설계된 도구인 [React 컴파일러](https://react.dev/learn/react-compiler/introduction)에 대한 지원이 포함되어 있습니다. 이렇게 하면 `useMemo` 및 `useCallback`을 사용하여 수동으로 메모할 필요성이 줄어듭니다.

Next.js에는 React 컴파일러를 더욱 효율적으로 만드는 SWC로 작성된 사용자 정의 성능 최적화가 포함되어 있습니다. 모든 파일에서 컴파일러를 실행하는 대신 Next.js는 프로젝트를 분석하고 관련 파일에만 React 컴파일러를 적용합니다. 이렇게 하면 불필요한 작업이 방지되고 Babel 플러그인을 단독으로 사용하는 것보다 빌드가 더 빨라집니다.

## 작동 방식

React 컴파일러는 Babel 플러그인을 통해 실행됩니다. 빌드 속도를 빠르게 유지하기 위해 Next.js는 JSX 또는 React 후크가 있는 파일과 같은 관련 파일에만 React 컴파일러를 적용하는 사용자 정의 SWC 최적화를 사용합니다.

이렇게 하면 모든 것을 컴파일하지 않고 성능 비용을 최소화할 수 있습니다. 기본 Rust 기반 컴파일러에 비해 여전히 약간 느린 빌드를 볼 수 있지만 영향은 작고 지역화되어 있습니다.

이를 사용하려면 `babel-plugin-react-compiler`을 설치하십시오.

```bash filename="Terminal"
npm install -D babel-plugin-react-compiler
```

그런 다음 `reactCompiler`에 `next.config.js` 옵션을 추가합니다.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: true,
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: true,
}

module.exports = nextConfig
```

## 주석

다음과 같이 "옵트인" 모드에서 실행되도록 컴파일러를 구성할 수 있습니다.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: {
    compilationMode: 'annotation',
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: {
    compilationMode: 'annotation',
  },
}

module.exports = nextConfig
```

그런 다음 React의 `"use memo"` 지시어를 사용하여 특정 구성 요소나 후크에 주석을 달아 선택할 수 있습니다.

```ts filename="app/page.tsx" switcher
export default function Page() {
  'use memo'
  // ...
}
```

```js filename="app/page.js" switcher
export default function Page() {
  'use memo'
  // ...
}
```

> **참고:** 반대 효과를 위해 React의 `"use no memo"` 지시문을 사용하여 구성 요소나 후크를 옵트아웃할 수도 있습니다.
