`staticGeneration*` 옵션을 사용하면 고급 사용 사례에 대한 정적 생성 프로세스를 구성할 수 있습니다.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    staticGenerationRetryCount: 1,
    staticGenerationMaxConcurrency: 8,
    staticGenerationMinPagesPerWorker: 25,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
const nextConfig = {
  experimental: {
    staticGenerationRetryCount: 1,
    staticGenerationMaxConcurrency: 8,
    staticGenerationMinPagesPerWorker: 25,
  },
}

export default nextConfig
```

## 구성 옵션

다음 옵션을 사용할 수 있습니다.

- `staticGenerationRetryCount`: 빌드가 실패하기 전에 실패한 페이지 생성을 다시 시도하는 횟수입니다.
- `staticGenerationMaxConcurrency`: 작업자당 처리할 최대 페이지 수입니다.
- `staticGenerationMinPagesPerWorker`: 새 작업자를 시작하기 전에 처리해야 할 최소 페이지 수입니다.
