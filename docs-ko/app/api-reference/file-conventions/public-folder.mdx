Next.js는 루트 디렉터리의 `public` 폴더 아래에서 이미지와 같은 정적 파일을 제공할 수 있습니다. 그러면 `public` 내부의 파일은 기본 URL(`/`)부터 시작하는 코드로 참조될 수 있습니다.

예를 들어, `public/avatars/me.png` 경로를 방문하면 `/avatars/me.png` 파일을 볼 수 있습니다. 해당 이미지를 표시하는 코드는 다음과 같습니다.

```jsx filename="avatar.js"
import Image from 'next/image'

export function Avatar({ id, alt }) {
  return <Image src={`/avatars/${id}.png`} alt={alt} width="64" height="64" />
}

export function AvatarOfMe() {
  return <Avatar id="me" alt="A portrait of me" />
}
```

## 캐싱

Next.js는(는) `public` 폴더의 자산이 변경될 수 있으므로 안전하게 캐시할 수 없습니다. 적용되는 기본 캐싱 헤더는 다음과 같습니다.

```jsx
Cache-Control: public, max-age=0
```
