The `mdx-components.js|tsx` 파일은 **필수**이며 이 파일이 없으면 작동하지 않습니다. 또한 이를 사용하여 [`@next/mdx` with App Router](../../guides/mdx.mdx)할 수 있습니다.[customize styles](../../guides/mdx.mdx#using-custom-styles-and-components).

프로젝트 루트에 있는 `mdx-components.tsx`(또는 `.js`) 파일을 사용하여 MDX 구성 요소를 정의합니다. 예를 들어, `pages` 또는 `app`과 동일한 수준에 있거나 해당되는 경우 `src` 내부에 있습니다.

```tsx filename="mdx-components.tsx" switcher
import type { MDXComponents } from 'mdx/types'

const components: MDXComponents = {}

export function useMDXComponents(): MDXComponents {
  return components
}
```

```js filename="mdx-components.js" switcher
const components = {}

export function useMDXComponents() {
  return components
}
```

## 수출

### `useMDXComponents` 함수

파일은 `useMDXComponents`라는 단일 함수를 내보내야 합니다. 이 함수는 어떤 인수도 허용하지 않습니다.

```tsx filename="mdx-components.tsx" switcher
import type { MDXComponents } from 'mdx/types'

const components: MDXComponents = {}

export function useMDXComponents(): MDXComponents {
  return components
}
```

```js filename="mdx-components.js" switcher
const components = {}

export function useMDXComponents() {
  return components
}
```
