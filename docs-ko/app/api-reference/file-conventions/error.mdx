An **오류** 파일을 사용하면 예상치 못한 런타임 오류를 처리하고 대체 UI를 표시할 수 있습니다.

<Image alt="error.js 특수 파일" srcLight="/docs/light/error-special-file.png" srcDark="/docs/dark/error-special-file.png" width="1600" height="606" />

```tsx filename="app/dashboard/error.tsx" switcher
'use client' // Error boundaries must be Client Components

import { useEffect } from 'react'

export default function Error({
  error,
  reset,
}: {
  error: Error & { digest?: string }
  reset: () => void
}) {
  useEffect(() => {
    // Log the error to an error reporting service
    console.error(error)
  }, [error])

  return (
    <div>
      <h2>Something went wrong!</h2>
      <button
        onClick={
          // Attempt to recover by trying to re-render the segment
          () => reset()
        }
      >
        Try again
      </button>
    </div>
  )
}
```

`error.js`은 [React 오류 경계](https://react.dev/reference/react/Component#catching-rendering-errors-with-an-error-boundary)에서 경로 세그먼트와 중첩된 하위 항목을 래핑합니다. 경계 내에서 오류가 발생하면 `error` 구성 요소가 대체 UI로 표시됩니다.

<Image alt="error.js 작동 방식" srcLight="/docs/light/error-overview.png" srcDark="/docs/dark/error-overview.png" width="1600" height="903" />

> **알면 좋은 점**:
>
> - The [React DevTools](https://react.dev/learn/react-developer-tools)를 사용하면 오류 경계를 전환하여 오류 상태를 테스트할 수 있습니다.
> - 오류가 상위 오류 경계까지 버블링되도록 하려면 `throw` 구성 요소를 렌더링할 때 `error`을 수행할 수 있습니다.

## 참조

### 소품

#### `error`

An instance of an [`Error`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Error) 개체의 인스턴스입니다.`error.js` Client Component.

> **알아두면 좋은 점:** 개발 중에 클라이언트에 전달된 `Error` 개체는 직렬화되고 더 쉬운 디버깅을 위해 원래 오류의 `message`을 포함합니다. 그러나 오류에 포함된 잠재적으로 민감한 세부 정보가 클라이언트에 유출되는 것을 방지하기 위해 **이 동작은 프로덕션에서는 다릅니다**.

#### `error.message`

- 클라이언트 구성 요소에서 전달된 오류에는 원래 `Error` 메시지가 표시됩니다.
- 서버 구성 요소에서 전달된 오류에는 식별자가 포함된 일반 메시지가 표시됩니다. 이는 민감한 정보가 유출되는 것을 방지하기 위한 것입니다. `errors.digest` 아래의 식별자를 사용하여 해당 서버 측 로그를 일치시킬 수 있습니다.

#### `error.digest`

발생한 오류의 자동 생성된 해시입니다. 서버 측 로그에서 해당 오류를 일치시키는 데 사용할 수 있습니다.

#### `reset`

오류의 원인은 일시적일 수 있습니다. 이러한 경우 다시 시도하면 문제가 해결될 수도 있습니다.

오류 구성 요소는 `reset()` 함수를 사용하여 사용자에게 오류 복구를 시도하라는 메시지를 표시할 수 있습니다. 실행되면 함수는 오류 경계의 내용을 다시 렌더링하려고 시도합니다. 성공하면 대체 오류 구성요소가 다시 렌더링된 결과로 대체됩니다.

```tsx filename="app/dashboard/error.tsx" switcher
'use client' // Error boundaries must be Client Components

export default function Error({
  error,
  reset,
}: {
  error: Error & { digest?: string }
  reset: () => void

  return (

      <h2>Something went wrong!</h2>
      <button onClick={() => reset()}>Try again</button>
    </div>
  )
```


## 예

### 전역 오류

흔하지는 않지만 `global-error.jsx`을 사용하여 루트 레이아웃이나 템플릿의 오류를 처리할 수 있습니다. 전역 오류 UI는 자체 [internationalization](../../guides/internationalization.mdx). Global error UI must define its own `<html>` 및 `<body>` 태그, 전역 스타일, 글꼴 또는 오류 페이지에 필요한 기타 종속성을 정의해야 합니다. 이 파일은 활성화되면 루트 레이아웃이나 템플릿을 대체합니다.

> **알아두면 좋은 정보**: 오류 경계는 [클라이언트 구성 요소](../../getting-started/server-and-client-components.mdx#using-client-components)여야 합니다. 이는 [`metadata` 및 `generateMetadata`](../../getting-started/metadata-and-og-images.mdx) 내보내기가 `global-error.jsx`에서 지원되지 않음을 의미합니다. 대안으로 React [`<title>`](https://react.dev/reference/react-dom/components/title) 구성 요소를 사용할 수 있습니다.

```tsx filename="app/global-error.tsx" switcher
'use client' // Error boundaries must be Client Components

export default function GlobalError({
  error,
  reset,
}: {
  error: Error & { digest?: string }
  reset: () => void
}) {
  return (
    // global-error must include html and body tags
    <html>
      <body>
        <h2>Something went wrong!</h2>
        <button onClick={() => reset()}>Try again</button>
      </body>
    </html>
  )
}
```


### 사용자 정의 오류 경계를 사용한 정상적인 오류 복구

클라이언트에서 렌더링이 실패하면 더 나은 사용자 경험을 위해 마지막으로 알려진 서버 렌더링 UI를 표시하는 것이 유용할 수 있습니다.

The `GracefullyDegradingErrorBoundary`은 오류가 발생하기 전에 현재 HTML를 캡처하고 보존하는 사용자 정의 오류 경계의 예입니다. 렌더링 오류가 발생하면 캡처된 HTML를 다시 렌더링하고 지속적인 알림 표시줄을 표시하여 사용자에게 알립니다.

```tsx filename="app/dashboard/error.tsx" switcher
'use client'

import React, { Component, ErrorInfo, ReactNode } from 'react'

interface ErrorBoundaryProps {
  children: ReactNode
  onError?: (error: Error, errorInfo: ErrorInfo) => void
}

interface ErrorBoundaryState {
  hasError: boolean
}

export class GracefullyDegradingErrorBoundary extends Component<
  ErrorBoundaryProps,
  ErrorBoundaryState
> {
  private contentRef: React.RefObject<HTMLDivElement | null>

  constructor(props: ErrorBoundaryProps) {
    super(props)
    this.state = { hasError: false }
    this.contentRef = React.createRef()
  }

  static getDerivedStateFromError(_: Error): ErrorBoundaryState {
    return { hasError: true }
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    if (this.props.onError) {
      this.props.onError(error, errorInfo)
    }
  }

  render() {
    if (this.state.hasError) {
      // Render the current HTML content without hydration
      return (
        <>
          <div
            ref={this.contentRef}
            suppressHydrationWarning
            dangerouslySetInnerHTML={{
              __html: this.contentRef.current?.innerHTML || '',
            }}
          />
          <div className="fixed bottom-0 left-0 right-0 bg-red-600 text-white py-4 px-6 text-center">
            <p className="font-semibold">
              An error occurred during page rendering
            </p>
          </div>
        </>
      )
    }

    return <div ref={this.contentRef}>{this.props.children}</div>
  }
}

export default GracefullyDegradingErrorBoundary
```
