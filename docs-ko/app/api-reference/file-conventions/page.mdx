The `page` 파일을 사용하면 경로에 **고유한** UI를 정의할 수 있습니다. 기본적으로 파일에서 구성 요소를 내보내는 페이지를 만들 수 있습니다.

```tsx filename="app/blog/[slug]/page.tsx" switcher
export default function Page({
  params,
  searchParams,
}: {
  params: Promise<{ slug: string }>
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  return <h1>My Page</h1>
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
export default function Page({ params, searchParams }) {
  return <h1>My Page</h1>
}
```

## 알아두면 좋은 점

- The `.js`, `.jsx` 또는 `.tsx` 파일 확장자를 `page`에 사용할 수 있습니다.
- A `page`은 항상 경로 하위 트리의 **리프**입니다.
- 경로 구간을 `page` 파일이 필요합니다.**publicly accessible**.
- 페이지는 기본적으로 [서버 구성 요소](https://react.dev/reference/rsc/server-components)이지만, [클라이언트 구성 요소](https://react.dev/reference/rsc/use-client)로 설정할 수 있습니다.

## 참조

### 소품

#### `params`(선택 사항)

루트 세그먼트부터 해당 페이지까지 [동적 경로 매개변수](dynamic-routes.mdx)를 포함하는 객체로 확인되는 프라미스입니다.

```tsx filename="app/shop/[slug]/page.tsx" switcher
export default async function Page({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
}
```

```jsx filename="app/shop/[slug]/page.js" switcher
export default async function Page({ params }) {
  const { slug } = await params
}
```

| 예시 경로 | URL | `params` |`app/shop/[slug]/page.js`            | `/shop/1`   | `Promise<{ slug: '1' }>`                |`app/shop/[category]/[item]/page.js` | `/shop/1/2` | `Promise<{ category: '1', item: '2' }>` |
| `app/shop/[...slug]/page.js`         | `/shop/1/2` | `Promise<{ slug: ['1', '2'] }>`         |

- Since the `params` prop는 promise가므로 값에 액세스하려면 `async/await` 또는 React의 [`use`](https://react.dev/reference/react/use) 함수를 사용해야 합니다.
  - 버전 14 이하에서는 `params`이 동기식 prop가었습니다. 이전 버전과의 호환성을 돕기 위해 Next.js 15에서 동기적으로 계속 액세스할 수 있지만 이 동작은 향후 더 이상 사용되지 않습니다.

#### `searchParams`(선택 사항)

현재 URL의 [검색 매개변수](https://developer.mozilla.org/docs/Learn/Common_questions/What_is_a_URL#parameters)를 포함하는 객체로 확인되는 프라미스입니다. 예를 들면:

```tsx filename="app/shop/page.tsx" switcher
export default async function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const filters = (await searchParams).filters
}
```

```jsx filename="app/shop/page.js" switcher
export default async function Page({ searchParams }) {
  const filters = (await searchParams).filters
}
```

클라이언트 구성 요소 **페이지**는 React의 `searchParams`에 액세스할 수도 있습니다.[`use`](https://react.dev/reference/react/use) hook:

```tsx filename="app/shop/page.tsx" switcher
'use client'
import { use } from 'react'

export default function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const filters = use(searchParams).filters
}
```

```jsx filename="app/page.jsx" switcher
'use client'
import { use } from 'react'

export default function Page({ searchParams }) {
  const filters = use(searchParams).filters
}
```

| 예 URL | `searchParams` |`/shop?a=1`     | `Promise<{ a: '1' }>`         |`/shop?a=1&b=2` | `Promise<{ a: '1', b: '2' }>` |
| `/shop?a=1&a=2` | `Promise<{ a: ['1', '2'] }>`  |

- 버전 14 이하에서는 `searchParams`이 동기식 prop가었습니다. 이전 버전과의 호환성을 돕기 위해 Next.js 15에서 동기적으로 계속 액세스할 수 있지만 이 동작은 향후 더 이상 사용되지 않습니다.`async/await` or React's [`use`](https://react.dev/reference/react/use) function to access the values.
  - In version 14 and earlier, `searchParams` was a synchronous prop. To help with backwards compatibility, you can still access it synchronously in Next.js 15, but this behavior will be deprecated in the future.
- `searchParams`은 값을 미리 알 수 없는 \*\***[Dynamic API](../../guides/caching.mdx#dynamic-rendering)** whose values cannot be known ahead of time. Using it will opt the page into **[dynamic rendering](../../guides/caching.mdx#dynamic-rendering)** at request time.\*\*입니다. 이를 사용하면 요청 시 페이지가 \*\*\*\*으로 선택됩니다.
- `searchParams`는 `URLSearchParams` 인스턴스가 아닌 일반 JavaScript 개체입니다.

### 페이지 소품 도우미

You can type pages with `PageProps`로 페이지를 입력하면 경로 리터럴에서 강력한 형식의 `params` 및 `searchParams`을 얻을 수 있습니다. `PageProps`은 전역적으로 사용 가능한 도우미입니다.

```tsx filename="app/blog/[slug]/page.tsx"
export default async function Page(props: PageProps<'/blog/[slug]'>) {
  const { slug } = await props.params
  const query = await props.searchParams
  return <h1>Blog Post: {slug}</h1>
}
```

> **알면 좋은 점**
>
> - 리터럴 경로(예: `'/blog/[slug]'`)를 사용하면 `params`에 대한 자동 완성 및 엄격한 키가 활성화됩니다.
> - 정적 경로는 `params`을 `{}`로 확인합니다.
> - 유형은 `next dev`, `next build` 중 또는 `next typegen`을 통해 생성됩니다.
> - 유형 생성 후 `PageProps` 도우미를 전역적으로 사용할 수 있습니다. 수입할 필요는 없습니다.

## 예

### Displaying content based on `params`

Using [동적 경로 세그먼트](dynamic-routes.mdx)를 사용하면 `params` 소품을 기반으로 페이지의 특정 콘텐츠를 표시하거나 가져올 수 있습니다.

```tsx filename="app/blog/[slug]/page.tsx" switcher
export default async function Page({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  return <h1>Blog Post: {slug}</h1>
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
export default async function Page({ params }) {
  const { slug } = await params
  return <h1>Blog Post: {slug}</h1>
}
```

### Handling filtering with `searchParams`

You can use the `searchParams` 소품을 사용하여 URL의 쿼리 문자열을 기반으로 필터링, 페이지 매김 또는 정렬을 처리할 수 있습니다.

```tsx filename="app/shop/page.tsx" switcher
export default async function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const { page = '1', sort = 'asc', query = '' } = await searchParams

  return (
    <div>
      <h1>Product Listing</h1>
      <p>Search query: {query}</p>
      <p>Current page: {page}</p>
      <p>Sort order: {sort}</p>
    </div>
  )
}
```

```jsx filename="app/shop/page.js" switcher
export default async function Page({ searchParams }) {
  const { page = '1', sort = 'asc', query = '' } = await searchParams

  return (
    <div>
      <h1>Product Listing</h1>
      <p>Search query: {query}</p>
      <p>Current page: {page}</p>
      <p>Sort order: {sort}</p>
    </div>
  )
}
```

### 클라이언트 구성 요소에서 `searchParams` 및 `params` 읽기

클라이언트 구성 요소(`searchParams`일 수 없음)에서 `params` 및 `async`을 사용하려면 React의 [`use`](https://react.dev/reference/react/use) 함수를 사용하여 약속을 읽을 수 있습니다.

```tsx filename="app/page.tsx" switcher
'use client'

import { use } from 'react'

export default function Page({
  params,
  searchParams,
}: {
  params: Promise<{ slug: string }>
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const { slug } = use(params)
  const { query } = use(searchParams)
}
```

```js filename="app/page.js" switcher
'use client'

import { use } from 'react'

export default function Page({ params, searchParams }) {
  const { slug } = use(params)
  const { query } = use(searchParams)
}
```
