Add or generate a `robots.txt` 디렉터리의 [로봇 제외 표준](https://en.wikipedia.org/wiki/Robots.txt#Standard)과 일치하는 **root** of `app` 파일을 추가하거나 생성하여 검색 엔진 크롤러에게 사이트에서 액세스할 수 있는 URL를 알려줍니다.

## 정적 `robots.txt`

```txt filename="app/robots.txt"
User-Agent: *
Allow: /
Disallow: /private/

Sitemap: https://acme.com/sitemap.xml
```

## 로봇 파일 생성

Add a `robots.js` 또는 `robots.ts` 파일을 추가합니다.[`Robots` object](#robots-object).

> **알아두면 좋은 정보**: `robots.js`는 [동적 API](../../../guides/caching.mdx#dynamic-apis) 또는 [동적 구성](../../../guides/caching.mdx#segment-config-options) 옵션을 사용하지 않는 한 기본적으로 캐시되는 특수 경로 처리기입니다.

```ts filename="app/robots.ts" switcher
import type { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: '/private/',
    },
    sitemap: 'https://acme.com/sitemap.xml',
  }
}
```

```js filename="app/robots.js" switcher
export default function robots() {
  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: '/private/',
    },
    sitemap: 'https://acme.com/sitemap.xml',
  }
}
```

출력:

```txt
User-Agent: *
Allow: /
Disallow: /private/

Sitemap: https://acme.com/sitemap.xml
```

### 특정 사용자 에이전트 맞춤설정

사용자 에이전트 배열을 `rules` 속성에 전달하여 개별 검색 엔진 봇이 사이트를 크롤링하는 방법을 사용자 정의할 수 있습니다. 예를 들면:

```ts filename="app/robots.ts" switcher
import type { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      {
        userAgent: 'Googlebot',
        allow: ['/'],
        disallow: '/private/',
      },
      {
        userAgent: ['Applebot', 'Bingbot'],
        disallow: ['/'],
      },
    ],
    sitemap: 'https://acme.com/sitemap.xml',
  }
}
```

```js filename="app/robots.js" switcher
export default function robots() {
  return {
    rules: [
      {
        userAgent: 'Googlebot',
        allow: ['/'],
        disallow: ['/private/'],
      },
      {
        userAgent: ['Applebot', 'Bingbot'],
        disallow: ['/'],
      },
    ],
    sitemap: 'https://acme.com/sitemap.xml',
  }
}
```

출력:

```txt
User-Agent: Googlebot
Allow: /
Disallow: /private/

User-Agent: Applebot
Disallow: /

User-Agent: Bingbot
Disallow: /

Sitemap: https://acme.com/sitemap.xml
```

### 로봇 개체

```tsx
type Robots = {
  rules:
    | {
        userAgent?: string | string[]
        allow?: string | string[]
        disallow?: string | string[]
        crawlDelay?: number
      }
    | Array<{
        userAgent: string | string[]
        allow?: string | string[]
        disallow?: string | string[]
        crawlDelay?: number
      }>
  sitemap?: string | string[]
  host?: string
}
```
