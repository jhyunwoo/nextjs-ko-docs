`useSelectedLayoutSegments`은 호출되는 레이아웃 **아래**에 있는 활성 경로 세그먼트를 읽을 수 있는 **클라이언트 구성 요소** 후크입니다.

탐색경로와 같은 활성 하위 세그먼트에 대한 지식이 필요한 상위 레이아웃에서 UI를 생성하는 데 유용합니다.

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useSelectedLayoutSegments } from 'next/navigation'

export default function ExampleClientComponent() {
  const segments = useSelectedLayoutSegments()

  return (
    <ul>
      {segments.map((segment, index) => (
        <li key={index}>{segment}</li>
      ))}
    </ul>
  )
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useSelectedLayoutSegments } from 'next/navigation'

export default function ExampleClientComponent() {
  const segments = useSelectedLayoutSegments()

  return (
    <ul>
      {segments.map((segment, index) => (
        <li key={index}>{segment}</li>
      ))}
    </ul>
  )
}
```

> **알면 좋은 점**:
>
> - Since `useSelectedLayoutSegments`는 [클라이언트 구성 요소](../../getting-started/server-and-client-components.mdx) 후크이고 레이아웃은 기본적으로 [서버 구성 요소](../../getting-started/server-and-client-components.mdx)이므로 `useSelectedLayoutSegments`는 일반적으로 레이아웃으로 가져온 클라이언트 구성 요소를 통해 호출됩니다.
> - 반환된 세그먼트에는 UI에 포함하지 않으려는 [경로 그룹](../file-conventions/route-groups.mdx)이 포함됩니다. [`filter`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter) 배열 방법을 사용하여 대괄호로 시작하는 항목을 제거할 수 있습니다.

## 매개변수

```tsx
const segments = useSelectedLayoutSegments(parallelRoutesKey?: string)
```

`useSelectedLayoutSegments` *선택적으로* [`parallelRoutesKey`](../file-conventions/parallel-routes.mdx#with-useselectedlayoutsegments)을 허용합니다. 이를 통해 해당 슬롯 내의 활성 경로 세그먼트를 읽을 수 있습니다.

## 반품

`useSelectedLayoutSegments`은 후크가 호출된 레이아웃에서 한 수준 아래의 활성 세그먼트를 포함하는 문자열 배열을 반환합니다. 또는 존재하지 않는 경우 빈 배열입니다.

예를 들어 아래 레이아웃과 URL가 주어지면 반환되는 세그먼트는 다음과 같습니다.

| 레이아웃 | URL 방문 | 반환된 세그먼트 |`app/layout.js`           | `/`                   | `[]`                        |
| `app/layout.js`           | `/dashboard`          | `['dashboard']`             |
| `app/layout.js`           | `/dashboard/settings` | `['dashboard', 'settings']` |
| `app/dashboard/layout.js` | `/dashboard`          | `[]`                        |
| `app/dashboard/layout.js` | `/dashboard/settings` | `['settings']`              |
