The `useLinkStatus` 후크를 사용하면 **보류 중** 상태를 추적할 수 있습니다. 예를 들어 탐색이 완료되는 동안 클릭한 링크에 대한 희미한 효과와 같은 미묘한 인라인 피드백에 사용합니다. `<Link>`을 사용한 경로 수준 대체 및 즉각적인 전환을 위한 프리페치를 선호합니다.`loading.js`, and prefetching for instant transitions.

`useLinkStatus`은 다음과 같은 경우에 유용합니다.

- [프리페치](../../getting-started/linking-and-navigating.mdx#prefetching)가 비활성화되었거나 진행 중이므로 탐색이 차단되었습니다.
- 대상 경로는 동적이며\*\* 즉각적인 탐색을 허용하는 **and** doesn't include a [`loading.js`](../file-conventions/loading.mdx) 파일을 포함하지 않습니다.

```tsx filename="app/hint.tsx" switcher
'use client'

import Link from 'next/link'
import { useLinkStatus } from 'next/link'

function Hint() {
  const { pending } = useLinkStatus()
  return (
    <span aria-hidden className={`link-hint ${pending ? 'is-pending' : ''}`} />
  )
}

export default function Header() {
  return (
    <header>
      <Link href="/dashboard" prefetch={false}>
        <span className="label">Dashboard</span> <Hint />
      </Link>
    </header>
  )
}
```

```jsx filename="app/hint.js" switcher

```

> **알면 좋은 점**:
>
> - `useLinkStatus`은 `Link` 구성 요소의 하위 구성 요소 내에서 사용해야 합니다.
> - 후크는 `prefetch={false}`가 `Link` 구성 요소에 설정된 경우 가장 유용합니다.
> - 연결된 경로가 프리페치된 경우 보류 상태를 건너뜁니다.
> - 여러 링크를 빠르게 연속해서 클릭하면 마지막 링크의 보류 상태만 표시됩니다.
> - 이 후크는 페이지 라우터에서 지원되지 않으며 항상 `{ pending: false }`
> - 인라인 표시기는 레이아웃 변경을 쉽게 도입할 수 있습니다. 고정 크기, 항상 렌더링되는 힌트 요소를 선호하고 불투명도를 전환하거나 애니메이션을 사용하세요.

## You might not need `useLinkStatus`

인라인 피드백을 추가하기 전에 다음 사항을 고려하세요.

- 대상은 정적이고 프로덕션에서 미리 가져오기 때문에 보류 단계를 건너뛸 수 있습니다.
- 경로에는 `loading.js` 파일이 있어 경로 수준 대체를 통한 즉각적인 전환이 가능합니다.

탐색 속도는 일반적으로 빠릅니다. 느린 전환을 식별할 때 `useLinkStatus`을 빠른 패치로 사용한 다음 반복하여 프리패치 또는 `loading.js` 대체를 통해 근본 원인을 수정합니다.

## 매개변수

```tsx
const { pending } = useLinkStatus()
```

`useLinkStatus`는 매개변수를 사용하지 않습니다.

## 반품

`useLinkStatus`은 단일 속성을 가진 객체를 반환합니다.

| 부동산 | 유형 | 설명 |`true` before history updates, `false` after |

## 예

### 인라인 링크 힌트

미리 가져오기가 완료되지 않은 경우 클릭을 확인하기 위해 레이아웃에 영향을 주지 않는 미묘하고 고정된 크기의 힌트를 추가하세요.

```tsx filename="app/components/loading-indicator.tsx" switcher
'use client'

import { useLinkStatus } from 'next/link'

export default function LoadingIndicator() {
  const { pending } = useLinkStatus()
  return (
    <span aria-hidden className={`link-hint ${pending ? 'is-pending' : ''}`} />
  )
}
```


```tsx filename="app/shop/layout.tsx" switcher
import Link from 'next/link'
import LoadingIndicator from './components/loading-indicator'

const links = [
  { href: '/shop/electronics', label: 'Electronics' },
  { href: '/shop/clothing', label: 'Clothing' },
  { href: '/shop/books', label: 'Books' },
]

function Menubar() {
  return (
    <div>
      {links.map((link) => (
        <Link key={link.label} href={link.href}>
          <span className="label">{link.label}</span> <LoadingIndicator />
        </Link>
      ))}
    </div>
  )
}

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <div>
      <Menubar />
      {children}
    </div>
  )
}
```

## 빠른 탐색을 우아하게 처리

새로운 경로로의 탐색이 빠른 경우 사용자에게 힌트가 불필요하게 깜박이는 것을 볼 수 있습니다. 사용자 경험을 개선하고 탐색이 완료되는 데 시간이 걸릴 때만 힌트를 표시하는 한 가지 방법은 초기 애니메이션 지연(예: 100ms)을 추가하고 애니메이션을 보이지 않는 상태로 시작하는 것입니다(예: `opacity: 0`).

```css filename="app/styles/global.css"
.link-hint {
  display: inline-block;
  width: 0.6em;
  height: 0.6em;
  margin-left: 0.25rem;
  border-radius: 9999px;
  background: currentColor;
  opacity: 0;
  visibility: hidden; /* reserve space without showing the hint */
}

.link-hint.is-pending {
  /* Animation 1: fade in after 100ms and keep final opacity */
  /* Animation 2: subtle pulsing while pending */
  visibility: visible;
  animation-name: fadeIn, pulse;
  animation-duration: 200ms, 1s;
  /* Appear only if navigation actually takes time */
  animation-delay: 100ms, 100ms;
  animation-timing-function: ease, ease-in-out;
  animation-iteration-count: 1, infinite;
  animation-fill-mode: forwards, none;
}

@keyframes fadeIn {
  to {
    opacity: 0.35;
  }
}
@keyframes pulse {
  50% {
    opacity: 0.15;
  }
}
```
