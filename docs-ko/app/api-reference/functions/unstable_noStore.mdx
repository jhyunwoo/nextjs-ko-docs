**버전 15에서는 [`connection`](connection.mdx)를 사용하는 것이 좋습니다.`unstable_noStore`.**

`unstable_noStore`을 사용하여 정적 렌더링을 선언적으로 선택 해제하고 특정 구성 요소를 캐시해서는 안 됨을 나타낼 수 있습니다.

```jsx
import { unstable_noStore as noStore } from 'next/cache';

export default async function ServerComponent() {
  noStore();
  const result = await db.query(...);
  ...
}
```

> **알면 좋은 점**:
>
> - `unstable_noStore`은 `cache: 'no-store'`의 `fetch`
> - `unstable_noStore`은 더 세부적이고 구성 요소별로 사용할 수 있으므로 `export const dynamic = 'force-dynamic'`보다 선호됩니다.

- Using `unstable_noStore`을 사용하면 정적 생성이 선택 해제되지 않습니다. 대신 결과를 캐시할지 여부를 결정하기 위해 캐시 구성을 따릅니다.[`unstable_cache`](unstable_cache.mdx) will not opt out of static generation. Instead, it will defer to the cache configuration to determine whether to cache the result or not.

## 사용법

If you prefer not to pass additional options to `fetch`, `cache: 'no-store'`와 같은 추가 옵션을 `next: { revalidate: 0 }`에 전달하지 않거나 `fetch`을 사용할 수 없는 경우 `noStore()`을 이러한 모든 사용 사례의 대체품으로 사용할 수 있습니다.

```jsx
import { unstable_noStore as noStore } from 'next/cache';

export default async function ServerComponent() {
  noStore();
  const result = await db.query(...);
  ...
}
```
