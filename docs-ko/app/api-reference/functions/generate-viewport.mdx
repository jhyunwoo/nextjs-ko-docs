정적 `viewport` 개체 또는 동적 `generateViewport` 함수를 사용하여 페이지의 초기 뷰포트를 사용자 정의할 수 있습니다.

> **알면 좋은 점**:
>
> - The `viewport` 개체 및 `generateViewport` 함수 내보내기는 **서버 구성 요소에서만 지원됩니다**.
> - 동일한 경로 세그먼트에서 `viewport` 개체와 `generateViewport` 기능을 모두 내보낼 수 없습니다.
> - If you're coming from migrating `metadata` 내보내기를 마이그레이션하는 경우 [metadata-to-viewport-export codemod](../../guides/upgrading/codemods.mdx#metadata-to-viewport-export)를 사용하여 변경 사항을 업데이트할 수 있습니다.

## The `viewport` 객체

뷰포트 옵션을 정의하려면 `viewport` 또는 `layout.jsx` 파일에서 `page.jsx` 개체를 내보냅니다.

```tsx filename="layout.tsx | page.tsx" switcher
import type { Viewport } from 'next'

export const viewport: Viewport = {
  themeColor: 'black',
}

export default function Page() {}
```

```jsx filename="layout.jsx | page.jsx" switcher
export const viewport = {
  themeColor: 'black',
}

export default function Page() {}
```

## `generateViewport` 함수

`generateViewport`는 하나 이상의 뷰포트 필드가 포함된 [`Viewport` 개체](#viewport-fields)를 반환해야 합니다.

```tsx filename="layout.tsx | page.tsx" switcher
export function generateViewport({ params }) {
  return {
    themeColor: '...',
  }
}
```

TypeScript에서 `params` 인수는 [`PageProps<'/route'>`](../file-conventions/page.mdx#page-props-helper) 또는 [`LayoutProps<'/route'>`](../file-conventions/layout.mdx#layout-props-helper)을 통해 입력할 수 있습니다. 정의되었습니다.`generateViewport` is defined.

```jsx filename="layout.js | page.js" switcher
export function generateViewport({ params }) {
  return {
    themeColor: '...',
  }
}
```

> **알면 좋은 점**:
>
> - 뷰포트가 런타임 정보에 의존하지 않는 경우 [`viewport` 개체](#the-viewport-object)를 사용하여 정의해야 합니다.`generateViewport`.

## 뷰포트 필드

### `themeColor`

Learn more about [`theme-color`](https://developer.mozilla.org/docs/Web/HTML/Element/meta/name/theme-color)에 대해 자세히 알아보세요.

**간단한 테마 색상**

```tsx filename="layout.tsx | page.tsx" switcher
import type { Viewport } from 'next'

export const viewport: Viewport = {
  themeColor: 'black',
}
```

```jsx filename="layout.jsx | page.jsx" switcher
export const viewport = {
  themeColor: 'black',
}
```

```html filename="<head> output" hideLineNumbers
<meta name="theme-color" content="black" />
```

**미디어 속성 포함**

```tsx filename="layout.tsx | page.tsx" switcher
import type { Viewport } from 'next'

export const viewport: Viewport = {
  themeColor: [
    { media: '(prefers-color-scheme: light)', color: 'cyan' },
    { media: '(prefers-color-scheme: dark)', color: 'black' },
  ],
}
```

```jsx filename="layout.jsx | page.jsx" switcher
export const viewport = {
  themeColor: [
    { media: '(prefers-color-scheme: light)', color: 'cyan' },
    { media: '(prefers-color-scheme: dark)', color: 'black' },
  ],
}
```

```html filename="<head> output" hideLineNumbers
<meta name="theme-color" media="(prefers-color-scheme: light)" content="cyan" />
<meta name="theme-color" media="(prefers-color-scheme: dark)" content="black" />
```

### `width`, `initialScale`, `maximumScale` 및 `userScalable`

> **알아두면 좋은 정보**: `viewport` 메타 태그는 자동으로 설정되며 기본값이면 충분하므로 일반적으로 수동 구성이 필요하지 않습니다. 그러나 정보는 완전성을 위해 제공됩니다.

```tsx filename="layout.tsx | page.tsx" switcher
import type { Viewport } from 'next'

export const viewport: Viewport = {
  width: 'device-width',
  initialScale: 1,
  maximumScale: 1,
  userScalable: false,
  // Also supported but less commonly used
  // interactiveWidget: 'resizes-visual',
}
```

```jsx filename="layout.jsx | page.jsx" switcher
export const viewport = {
  width: 'device-width',
  initialScale: 1,
  maximumScale: 1,
  userScalable: false,
  // Also supported but less commonly used
  // interactiveWidget: 'resizes-visual',
}
```

```html filename="<head> output" hideLineNumbers
<meta
  name="viewport"
  content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no"
/>
```

## 캐시 구성요소 포함

When [캐시 구성 요소](../../getting-started/cache-components.mdx)가 활성화되면 `generateViewport`은 다른 구성 요소와 동일한 규칙을 따릅니다. 뷰포트가 런타임 데이터(`cookies()`, `headers()`, `params`, `searchParams`)에 액세스하거나 캐시되지 않은 데이터 가져오기를 수행하는 경우 요청 시간을 연기합니다.

메타데이터와 달리 뷰포트는 초기 페이지 로드 UI에 영향을 주기 때문에 스트리밍할 수 없습니다. `generateViewport`이 요청 시간을 연기하는 경우 페이지는 해결될 때까지 차단되어야 합니다.

뷰포트가 외부 데이터에 의존하지만 런타임 데이터에 의존하지 않는 경우 `use cache`을 사용하세요.

```tsx filename="app/layout.tsx" highlight={2}
export async function generateViewport() {
  'use cache'
  const { width, initialScale } = await db.query('viewport-size')
  return { width, initialScale }
}
```

뷰포트에 실제로 런타임 데이터가 필요한 경우 문서 `<body>`을 Suspense 경계로 래핑하여 전체 경로가 동적이어야 함을 알립니다.

```tsx filename="app/layout.tsx" highlight={1,11-15}
import { Suspense } from 'react'
import { cookies } from 'next/headers'

export async function generateViewport() {
  const cookieJar = await cookies()
  return {
    themeColor: cookieJar.get('theme-color')?.value,
  }
}

export default function RootLayout({ children }) {
  return (
    <Suspense>
      <html>
        <body>{children}</body>
      </html>
    </Suspense>
  )
}
```

캐싱은 정적 쉘 생성을 허용하므로 선호됩니다. Suspense에서 `body` 문서를 래핑한다는 것은 요청이 도착할 때 즉시 보낼 정적 셸이나 콘텐츠가 없다는 것을 의미하므로 모든 요청이 준비될 때까지 전체 경로가 차단됩니다.

> **알아두면 좋은 정보**: [다중 루트 레이아웃](../file-conventions/layout.mdx#root-layout)을 사용하여 완전히 동적 뷰포트를 특정 경로로 분리하는 동시에 애플리케이션의 다른 경로가 정적 셸을 생성하도록 허용합니다.

## 유형

You can add type safety to your viewport object by using the `Viewport` 유형을 사용하여 뷰포트 객체에 유형 안전성을 추가할 수 있습니다. IDE에서 [내장 TypeScript 플러그인](../config/typescript.mdx)을 사용하는 경우 유형을 수동으로 추가할 필요는 없지만 원하는 경우 명시적으로 추가할 수 있습니다.

### `viewport` 객체

```tsx
import type { Viewport } from 'next'

export const viewport: Viewport = {
  themeColor: 'black',
}
```

### `generateViewport` 함수

#### 일반 함수

```tsx
import type { Viewport } from 'next'

export function generateViewport(): Viewport {
  return {
    themeColor: 'black',
  }
}
```

#### 세그먼트 소품 포함

```tsx
import type { Viewport } from 'next'

type Props = {
  params: Promise<{ id: string }>
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}

export function generateViewport({ params, searchParams }: Props): Viewport {
  return {
    themeColor: 'black',
  }
}

export default function Page({ params, searchParams }: Props) {}
```

#### JavaScript 프로젝트

JavaScript 프로젝트의 경우 JSDoc를 사용하여 유형 안전성을 추가할 수 있습니다.

```js
/** @type {import("next").Viewport} */
export const viewport = {
  themeColor: 'black',
}
```
