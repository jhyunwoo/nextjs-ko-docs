`cookies`은 **비동기** 기능입니다.[Server Components](../../getting-started/server-and-client-components.mdx), and read/write outgoing request cookies in [Server Functions](../../getting-started/updating-data.mdx) or [Route Handlers](../file-conventions/route.mdx).

```tsx filename="app/page.tsx" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')
  return '...'
}
```

```js filename="app/page.js" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')
  return '...'
}
```

## 참조

### 방법

다음 방법을 사용할 수 있습니다.

| 방법 | 반환 유형 | 설명 |`get('name')`               | Object           | Accepts a cookie name and returns an object with the name and value.            |`getAll()`                  | Array of objects | Returns a list of all the cookies with a matching name.                         |
| `has('name')`               | Boolean          | Accepts a cookie name and returns a boolean based on if the cookie exists.      |
| `set(name, value, options)` | -                | Accepts a cookie name, value, and options and sets the outgoing request cookie. |
| `delete(name)`              | -                | Accepts a cookie name and deletes the cookie.                                   |
| `toString()`                | String           | Returns a string representation of the cookies.                                 |

- The `.delete` 메서드는 다음에서만 호출할 수 있습니다.
  - In a [서버 기능](../../getting-started/updating-data.mdx) 또는 [경로 처리기](../file-conventions/route.mdx)에서.
  - If it belongs to the same domain from which `.set`이 호출되는 동일한 도메인에 속하는 경우. 와일드카드 도메인의 경우 특정 하위 도메인이 정확히 일치해야 합니다. 또한 삭제하려는 쿠키와 동일한 프로토콜(HTTP 또는 HTTPS)에서 코드를 실행해야 합니다.
- HTTP에서는 스트리밍 시작 후 쿠키 설정을 허용하지 않으므로 `.set`을 사용해야 합니다.[Server Function](../../getting-started/updating-data.mdx) or [Route Handler](../file-conventions/route.mdx).

## 서버 구성 요소의 쿠키 동작 이해

서버 구성 요소에서 쿠키를 사용할 때 쿠키는 기본적으로 클라이언트측 저장 메커니즘이라는 점을 이해하는 것이 중요합니다.

- **쿠키 읽기**는 클라이언트 브라우저가 HTTP 요청 헤더를 통해 서버에 보내는 쿠키 데이터에 액세스하기 때문에 서버 구성 요소에서 작동합니다.
- **쿠키 설정**이 지원되지 않습니다. 쿠키를 수정하려면 클라이언트에서 서버 기능을 호출하거나 경로 처리기를 사용하세요.

서버는 (`Set-Cookie` 헤더를 통해) 브라우저에 쿠키를 저장하라고 지시하는 명령만 보낼 수 있습니다. 실제 저장은 클라이언트 측에서 발생합니다. 이것이 바로 상태(`.set`, `.delete`)를 수정하는 쿠키 작업이 응답 헤더가 올바르게 설정될 수 있는 서버 기능 또는 경로 처리기에서 수행되어야 하는 이유입니다.

## 서버 기능의 쿠키 동작 이해

서버 함수에서 쿠키를 설정하거나 삭제한 후, 함수가 [서버 작업](../../getting-started/updating-data.mdx#what-are-server-functions)으로 사용될 때(예: 양식의 `action` 소품에 전달됨) Next.js는 단일 서버 왕복에서 업데이트된 UI와 새 데이터를 모두 반환할 수 있습니다. [캐싱 가이드](../../guides/caching.mdx#cookies)를 참조하세요.

UI는 마운트 해제되지 않지만, 서버에서 들어오는 데이터에 의존하는 효과가 다시 실행됩니다.

캐시된 데이터도 새로 고치려면 함수 내에서 [`revalidatePath`](revalidatePath.mdx) 또는 [`revalidateTag`](revalidateTag.mdx)을 호출하세요.

### 모든 쿠키 가져오기 메서드를 사용하여 이름이 일치하는 모든 쿠키를 가져올 수 있습니다. 을 지정하지 않으면 사용 가능한 모든 쿠키가 반환됩니다.

You can use the `(await cookies()).getAll()` 메서드를 사용하여 쿠키를 설정할 수 있습니다. `name` is unspecified, it returns all the available cookies.는 선택 사항입니다.

```tsx filename="app/page.tsx" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  return cookieStore.getAll().map((cookie) => (
    <div key={cookie.name}>
      <p>Name: {cookie.name}</p>
      <p>Value: {cookie.value}</p>
    </div>
  ))
}
```

```jsx filename="app/page.js" switcher

  return cookieStore.getAll().map((cookie) => (
    <div key={cookie.name}>
      <p>Name: {cookie.name}</p>
      <p>Value: {cookie.value}</p>
    </div>
  ))
}
```

### 쿠키가 있는지 확인하기

You can use the `(await cookies()).set(name, value, options)` 메서드를 사용하여 쿠키가 있는지 확인할 수 있습니다.[Server Function](../../getting-started/updating-data.mdx) or [Route Handler](../file-conventions/route.mdx) to set a cookie. The [`options` object](#options) is optional.

```tsx filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function create(data) {
  const cookieStore = await cookies()

  cookieStore.set('name', 'lee')
  // or
  cookieStore.set('name', 'lee', { secure: true })
  // or
  cookieStore.set({
    name: 'name',
    value: 'lee',
    httpOnly: true,
    path: '/',
  })
}
```



### Deleting cookies

이름이 같고 값이 비어 있는 새 쿠키를 설정합니다.

Using the `delete()`을 0으로 설정하면 쿠키가 즉시 만료됩니다. 는 초 단위의 값을 허용합니다.

```tsx filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function deleteCookie(data) {
  const cookieStore = await cookies()
  cookieStore.delete('name')
}
```

```js filename="app/actions.js" switcher

import { cookies } from 'next/headers'

export async function deleteCookie(data) {
```
