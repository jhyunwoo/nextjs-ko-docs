Next.js에는 `.scss` 및 `.sass` 확장을 모두 사용하여 패키지를 설치한 후 Sass와의 통합을 기본적으로 지원합니다. CSS 모듈과 `.module.scss` 또는 `.module.sass` 확장을 통해 구성 요소 수준 Sass를 사용할 수 있습니다.

먼저 [`sass`](https://github.com/sass/sass)을 설치합니다.

```bash filename="Terminal"
npm install --save-dev sass
```

> **알면 좋은 점**:
>
> Sass는 [두 가지 다른 구문](https://sass-lang.com/documentation/syntax)을 지원하며 각각 고유한 확장이 있습니다.
> `.scss` 확장을 사용하려면 [SCSS 구문](https://sass-lang.com/documentation/syntax#scss)을 사용해야 합니다.
> `.sass` 확장을 사용하려면 [들여쓰기 구문("Sass")](https://sass-lang.com/documentation/syntax#the-indented-syntax)을 사용해야 합니다.
>
> 무엇을 선택해야 할지 잘 모르겠으면 CSS의 상위 집합인 `.scss` 확장으로 시작하세요.
> 들여쓰기 구문("Sass").

### Sass 옵션 사용자 정의

Sass 옵션을 구성하려면 `sassOptions`에서 `next.config`을 사용하세요.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

module.exports = nextConfig
```

#### 구현

You can use the `implementation` 속성을 사용하여 사용할 Sass 구현을 지정할 수 있습니다. 기본적으로 Next.js는 [`sass`](https://www.npmjs.com/package/sass) 패키지를 사용합니다.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

module.exports = nextConfig
```

### Sass 변수

Next.js는 CSS 모듈 파일에서 내보낸 Sass 변수를 지원합니다.

예를 들어 내보낸 `primaryColor` Sass 변수를 사용하면 다음과 같습니다.

```scss filename="app/variables.module.scss"
$primary-color: #64ff00;

:export {
  primaryColor: $primary-color;
}
```

```jsx filename="app/page.js"
// maps to root `/` URL

import variables from './variables.module.scss'

export default function Page() {
  return <h1 style={{ color: variables.primaryColor }}>Hello, Next.js!</h1>
}
```
