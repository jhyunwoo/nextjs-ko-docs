**초안 모드**를 사용하면 Next.js 애플리케이션에서 헤드리스 CMS의 초안 콘텐츠를 미리 볼 수 있습니다. 이는 [동적 렌더링](caching.mdx#dynamic-rendering)으로 전환하고 전체 사이트를 다시 구축하지 않고도 변경 사항 초안을 볼 수 있으므로 빌드 시 생성되는 정적 페이지에 유용합니다.

이 페이지에서는 초안 모드를 활성화하고 사용하는 방법을 안내합니다.

## 1단계: 경로 처리기 생성

Create a [경로 처리기](../api-reference/file-conventions/route.mdx)를 만듭니다. 이름은 무엇이든 가질 수 있습니다(예: `app/api/draft/route.ts`).

```ts filename="app/api/draft/route.ts" switcher
export async function GET(request: Request) {
  return new Response('')
}
```

```js filename="app/api/draft/route.js" switcher
export async function GET() {
  return new Response('')
}
```

그런 다음 [`draftMode`](../api-reference/functions/draft-mode.mdx) 함수를 가져오고 `enable()` 메서드를 호출합니다.

```ts filename="app/api/draft/route.ts" switcher
import { draftMode } from 'next/headers'

export async function GET(request: Request) {
  const draft = await draftMode()
  draft.enable()
  return new Response('Draft mode is enabled')
}
```

```js filename="app/api/draft/route.js" switcher
import { draftMode } from 'next/headers'

export async function GET(request) {
  const draft = await draftMode()
  draft.enable()
  return new Response('Draft mode is enabled')
}
```

초안 모드를 활성화하기 위한 **쿠키**가 설정됩니다. 이 쿠키가 포함된 후속 요청은 초안 모드를 트리거하고 정적으로 생성된 페이지의 동작을 변경합니다.

You can test this manually by visiting `/api/draft`를 방문하고 브라우저의 개발자 도구를 확인하여 수동으로 테스트할 수 있습니다. `Set-Cookie`라는 쿠키가 포함된 `__prerender_bypass` 응답 헤더를 확인하세요.

## 2단계: 헤드리스 CMS에서 경로 핸들러에 액세스

> 이 단계에서는 사용 중인 헤드리스 CMS가 **맞춤 초안 URL** 설정을 지원한다고 가정합니다. 그렇지 않은 경우에도 이 방법을 사용하여 초안 URL를 보호할 수 있지만 초안 URL를 수동으로 구성하고 액세스해야 합니다. 구체적인 단계는 사용 중인 헤드리스 CMS에 따라 달라집니다.

헤드리스 CMS에서 경로 핸들러에 안전하게 액세스하려면:

1. 원하는 토큰 생성기를 사용하여 **비밀 토큰 문자열**을 만듭니다. 이 비밀은 Next.js 앱과 헤드리스 CMS에만 알려집니다.
1. 헤드리스 CMS가 사용자 정의 초안 URL 설정을 지원하는 경우 초안 URL를 지정합니다(이는 경로 핸들러가 `app/api/draft/route.ts`에 있다고 가정함). 예를 들면:

```bash filename="Terminal"
https://<your-site>/api/draft?secret=<token>&slug=<path>
```

> - `<your-site>`은 배포 도메인이어야 합니다.
> - `<token>`은 생성한 비밀 토큰으로 바꿔야 합니다.
> - `<path>`은 보려는 페이지의 경로여야 합니다. `/posts/one`을 보려면 `&slug=/posts/one`을 사용해야 합니다.
>
> 헤드리스 CMS를 사용하면 URL 초안에 변수를 포함하여 `<path>`이 CMS의 데이터를 기반으로 다음과 같이 동적으로 설정할 수 있습니다. `&slug=/posts/{entry.fields.slug}`

3. 경로 처리기에서 비밀이 일치하는지, `slug` 매개변수가 있는지 확인하고(그렇지 않으면 요청이 실패해야 함) `draftMode.enable()`를 호출하여 쿠키를 설정합니다. 그런 다음 브라우저를 `slug`에 지정된 경로로 리디렉션합니다.

```ts filename="app/api/draft/route.ts" switcher
import { draftMode } from 'next/headers'
import { redirect } from 'next/navigation'

export async function GET(request: Request) {
  // Parse query string parameters
  const { searchParams } = new URL(request.url)
  const secret = searchParams.get('secret')
  const slug = searchParams.get('slug')

  // Check the secret and next parameters
  // This secret should only be known to this Route Handler and the CMS
  if (secret !== 'MY_SECRET_TOKEN' || !slug) {
    return new Response('Invalid token', { status: 401 })
  }

  // Fetch the headless CMS to check if the provided `slug` exists
  // getPostBySlug would implement the required fetching logic to the headless CMS
  const post = await getPostBySlug(slug)

  // If the slug doesn't exist prevent draft mode from being enabled
  if (!post) {
    return new Response('Invalid slug', { status: 401 })
  }

  // Enable Draft Mode by setting the cookie
  const draft = await draftMode()
  draft.enable()

  // Redirect to the path from the fetched post
  // We don't redirect to searchParams.slug as that might lead to open redirect vulnerabilities
  redirect(post.slug)
}
```

## 3단계: 초안 콘텐츠 미리보기

다음 단계는 페이지를 업데이트하여 `draftMode().isEnabled` 값을 확인하는 것입니다.

쿠키가 설정된 페이지를 요청하면 (빌드 시간이 아닌) **요청 시간**에 데이터를 가져옵니다.또한 의 값은 이 됩니다.

헤드리스 CMS에서 초안 경로 처리기(`isEnabled` 및 `true` 포함)에 액세스하거나 URL를 수동으로 사용하면 이제 초안 콘텐츠를 볼 수 있습니다. 그리고 게시하지 않고 초안을 업데이트하면 초안을 볼 수 있습니다.

```tsx filename="app/page.tsx" switcher
// page that fetches data
import { draftMode } from 'next/headers'

async function getData() {
  const { isEnabled } = await draftMode()

  const url = isEnabled
    ? 'https://draft.example.com'
    : 'https://production.example.com'

  const res = await fetch(url)

  return res.json()
}

export default async function Page() {
  const { title, desc } = await getData()

  return (
    <main>
      <h1>{title}</h1>
      <p>{desc}</p>
    </main>
  )
}
```

```jsx filename="app/page.js" switcher
// page that fetches data

export default async function Page() {

  return (
    <main>
      <h1>{title}</h1>
      <p>{desc}</p>
    </main>
  )
}
```

If you access the draft Route Handler (with `secret` and `slug`) from your headless CMS or manually using the URL, you should now be able to see the draft content. And, if you update your draft without publishing, you should be able to view the draft.
