## 13에서 14로 업그레이드

Next.js 버전 14로 업데이트하려면 원하는 패키지 관리자를 사용하여 다음 명령을 실행하세요.

```bash filename="Terminal"
npm i next@next-14 react@18 react-dom@18 && npm i eslint-config-next@next-14 -D
```

```bash filename="Terminal"
yarn add next@next-14 react@18 react-dom@18 && yarn add eslint-config-next@next-14 -D
```

```bash filename="Terminal"
pnpm i next@next-14 react@18 react-dom@18 && pnpm i eslint-config-next@next-14 -D
```

```bash filename="Terminal"
bun add next@next-14 react@18 react-dom@18 && bun add eslint-config-next@next-14 -D
```

> **알아두면 좋은 점:** TypeScript를 사용하는 경우 `@types/react` 및 `@types/react-dom`도 최신 버전으로 업그레이드하세요.

### v14 요약

- 16.x가 수명이 종료되었으므로 최소 Node.js 버전이 16.14에서 18.17로 늘어났습니다.
- The `next export` 명령이 `output: 'export'` 구성을 위해 제거되었습니다. 자세한 내용은 [문서](https://nextjs.org/docs/app/guides/static-exports)를 참조하세요.
- The `next/server`에 대한 `ImageResponse` 가져오기 이름이 `next/og`로 변경되었습니다. 가져오기 이름을 안전하고 자동으로 바꾸는 [codemod를 사용할 수 있습니다](codemods.mdx#next-og-import).
- 내장된 `@next/font`을 위해 `next/font` 패키지가 완전히 제거되었습니다. 가져오기 이름을 안전하고 자동으로 바꾸는 [codemod를 사용할 수 있습니다](codemods.mdx#built-in-next-font).
- The WASM target for `next-swc`에 대한 WASM 대상이 제거되었습니다.
