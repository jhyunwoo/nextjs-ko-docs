Playwright는 단일 API를 사용하여 Chromium, Firefox 및 WebKit를 자동화할 수 있는 테스트 프레임워크입니다. 이를 사용하여 **End-to-End(E2E)** 테스트를 작성할 수 있습니다. 이 가이드에서는 Next.js를 사용하여 Playwright를 설정하고 첫 번째 테스트를 작성하는 방법을 보여줍니다.

## 빠른 시작

시작하는 가장 빠른 방법은 `create-next-app`을 사용하는 것입니다. 이렇게 하면 Playwright가 구성된 완전한 Next.js 프로젝트가 생성됩니다.[with-playwright example](https://github.com/vercel/next.js/tree/canary/examples/with-playwright). This will create a Next.js project complete with Playwright configured.

```bash filename="Terminal"
npx create-next-app@latest --example with-playwright with-playwright-app
```

## 수동 설정

Playwright를 설치하려면 다음 명령을 실행하세요.

```bash filename="Terminal"
npm init playwright
# or
yarn create playwright
# or
pnpm create playwright
```

그러면 `playwright.config.ts` 파일 추가를 포함하여 프로젝트에 맞게 Playwright를 설정하고 구성하기 위한 일련의 프롬프트가 표시됩니다. 단계별 안내는 [극작가 설치 가이드](https://playwright.dev/docs/intro#installation)를 참고하세요.

## 첫 번째 극작가 E2E 테스트 만들기

두 개의 새로운 Next.js 페이지를 생성합니다:

```tsx filename="app/page.tsx"
import Link from 'next/link'

export default function Page() {
  return (
    <div>
      <h1>Home</h1>
      <Link href="/about">About</Link>
    </div>
  )
}
```

```tsx filename="app/about/page.tsx"
import Link from 'next/link'

export default function Page() {
  return (
    <div>
      <h1>About</h1>
      <Link href="/">Home</Link>
    </div>
  )
}
```

그런 다음 탐색이 올바르게 작동하는지 확인하는 테스트를 추가합니다.

```ts filename="tests/example.spec.ts"
import { test, expect } from '@playwright/test'

test('should navigate to the about page', async ({ page }) => {
  // Start from the index page (the baseURL is set via the webServer in the playwright.config.ts)
  await page.goto('http://localhost:3000/')
  // Find an element with the text 'About' and click on it
  await page.click('text=About')
  // The new URL should be "/about" (baseURL is used there)
  await expect(page).toHaveURL('http://localhost:3000/about')
  // The new page should contain an h1 with "About"
  await expect(page.locator('h1')).toContainText('About')
})
```

> **알아두면 좋은 정보**: `page.goto("/")` `page.goto("http://localhost:3000/")` 대신 [`"baseURL": "http://localhost:3000"`](https://playwright.dev/docs/api/class-testoptions#test-options-base-url) to the `playwright.config.ts`을 사용할 수 있습니다.[configuration file](https://playwright.dev/docs/test-configuration).

### 극작가 테스트 실행

Playwright는 Chromium, Firefox 및 Webkit의 세 가지 브라우저를 사용하여 애플리케이션을 탐색하는 사용자를 시뮬레이션합니다. 이를 위해서는 Next.js 서버가 실행 중이어야 합니다. 애플리케이션이 작동하는 방식과 더욱 유사하도록 프로덕션 코드에 대해 테스트를 실행하는 것이 좋습니다.

Run `npm run build` 및 `npm run start`를 실행한 다음 다른 터미널 창에서 `npx playwright test`을 실행하여 Playwright 테스트를 실행합니다.

> **알아두면 좋은 정보**: 또는 [`webServer`](https://playwright.dev/docs/test-webserver/) 기능을 사용하여 Playwright가 개발 서버를 시작하고 완전히 사용 가능해질 때까지 기다리도록 할 수 있습니다.

### CI(지속적 통합)에서 Playwright 실행

Playwright는 기본적으로 [헤드리스 모드](https://playwright.dev/docs/ci#running-headed)에서 테스트를 실행합니다. 모든 Playwright 종속성을 설치하려면 `npx playwright install-deps`을 실행하세요.
