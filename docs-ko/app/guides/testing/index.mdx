React 및 Next.js에는 작성할 수 있는 몇 가지 유형의 테스트가 있으며 각각 고유한 목적과 사용 사례가 있습니다. 이 페이지에서는 애플리케이션을 테스트하는 데 사용할 수 있는 유형 및 일반적으로 사용되는 도구에 대한 개요를 제공합니다.

## 테스트 유형

- **단위 테스트**에는 개별 단위(또는 코드 블록)를 격리하여 테스트하는 작업이 포함됩니다. React에서 단위는 단일 기능, 후크 또는 구성 요소일 수 있습니다.
  - **구성요소 테스트**는 테스트의 기본 주제가 React 구성요소인 단위 테스트의 보다 집중된 버전입니다. 여기에는 구성 요소가 렌더링되는 방식, 소품과의 상호 작용 및 사용자 이벤트에 대한 응답 동작을 테스트하는 작업이 포함될 수 있습니다.
  - **통합 테스트**에는 여러 장치가 함께 작동하는 방식을 테스트하는 작업이 포함됩니다. 이는 구성 요소, 후크 및 기능의 조합일 수 있습니다.
- **엔드 투 엔드(E2E) 테스트**에는 브라우저와 같은 실제 사용자 시나리오를 시뮬레이션하는 환경에서 사용자 흐름을 테스트하는 작업이 포함됩니다. 이는 프로덕션과 유사한 환경에서 특정 작업(예: 가입 흐름)을 테스트하는 것을 의미합니다.
- **스냅샷 테스트**에는 구성 요소의 렌더링된 출력을 캡처하고 이를 스냅샷 파일에 저장하는 작업이 포함됩니다. 테스트가 실행되면 구성 요소의 현재 렌더링된 출력이 저장된 스냅샷과 비교됩니다. 스냅샷의 변경 사항은 예상치 못한 동작 변경 사항을 나타내는 데 사용됩니다.

## 비동기 서버 구성요소

Since `async` 서버 구성 요소는 React 생태계에 처음 도입되었기 때문에 일부 도구는 이를 완전히 지원하지 않습니다. 그동안 **단위 테스트** 대신 **엔드 투 엔드 테스트**를 사용하는 것이 좋습니다.`async` components.
