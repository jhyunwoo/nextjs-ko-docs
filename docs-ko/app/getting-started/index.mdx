Next.js 문서에 오신 것을 환영합니다!

이 **시작하기** 섹션은 첫 번째 Next.js 앱을 만들고 모든 프로젝트에서 사용할 핵심 기능을 배우는 데 도움이 됩니다.

## 사전 필수 지식

우리 문서에서는 웹 개발에 어느 정도 익숙하다고 가정합니다. 시작하기 전에 다음 사항에 익숙하다면 도움이 될 것입니다.

- HTML
- CSS
- JavaScript
- React

React를 처음 사용하거나 복습이 필요한 경우 [React Foundations 과정](https://nextjs.org/learn/react-foundations) 및 배우면서 애플리케이션을 구축할 수 있는 [Next.js Foundations 과정](https://nextjs.org/learn/dashboard-app)부터 시작하는 것이 좋습니다.
