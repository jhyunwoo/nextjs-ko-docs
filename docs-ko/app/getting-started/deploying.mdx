## Node.js 서버

Next.js는 Node.js를 지원하는 모든 공급자에 배포될 수 있습니다. `package.json`에 `"build"` 및 `"start"` 스크립트가 있는지 확인하세요.

```json filename="package.json"
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start"
  }
}
```

그런 다음 `npm run build`을 실행하여 애플리케이션을 빌드하고 `npm run start`을 실행하여 Node.js 서버를 시작합니다. 이 서버는 모든 Next.js 기능을 지원합니다. 필요한 경우 [사용자 정의 서버](../guides/custom-server.mdx)로 꺼낼 수도 있습니다.

Node.js 배포는 모든 Next.js 기능을 지원합니다. 인프라에 맞게 [구성](../guides/self-hosting.mdx)하는 방법을 알아보세요.

## 도커

Next.js는 [Docker](https://www.docker.com/) 컨테이너를 지원하는 모든 공급자에 배포될 수 있습니다. 여기에는 Kubernetes와 같은 컨테이너 오케스트레이터나 Docker를 실행하는 클라우드 공급자가 포함됩니다.

Docker 배포는 모든 Next.js 기능을 지원합니다. 인프라에 맞게 [구성](../guides/self-hosting.mdx)하는 방법을 알아보세요.

> **개발 참고 사항:** Docker는 프로덕션 배포에 탁월하지만 더 나은 성능을 위해 Mac 및 Windows에서 개발하는 동안 Docker 대신 로컬 개발(`npm run dev`)을 사용하는 것이 좋습니다. [지역 개발 최적화에 대해 자세히 알아보세요](../guides/local-development.mdx).

## 정적 내보내기

Next.js를 사용하면 정적 사이트 또는 [단일 페이지 애플리케이션(SPA)](../guides/single-page-applications.mdx)으로 시작한 다음 나중에 선택적으로 업그레이드하여 서버가 필요한 기능을 사용할 수 있습니다.

Next.js는 [정적 내보내기](../guides/static-exports.mdx)를 지원하므로 HTML/CSS/JS 정적 자산을 제공할 수 있는 모든 웹 서버에 배포하고 호스팅할 수 있습니다. 여기에는 AWS S3, Nginx 또는 Apache와 같은 도구가 포함됩니다.

Running as a [정적 내보내기](../guides/static-exports.mdx)로 실행하면 서버가 필요한 Next.js 기능을 지원하지 **않습니다**. [자세히 알아보기](../guides/static-exports.mdx#unsupported-features).
