## 순풍 CSS

[Tailwind CSS](https://tailwindcss.com/)는 사용자 정의 디자인을 구축하기 위해 하위 수준 유틸리티 클래스를 제공하는 유틸리티 우선 CSS 프레임워크입니다.

Tailwind CSS 설치:

```bash package="pnpm"
pnpm add -D tailwindcss @tailwindcss/postcss
```

```bash package="npm"
npm install -D tailwindcss @tailwindcss/postcss
```

```bash package="yarn"
yarn add -D tailwindcss @tailwindcss/postcss
```

```bash package="bun"
bun add -D tailwindcss @tailwindcss/postcss
```

Add the PostCSS plugin to your `postcss.config.mjs` 파일에 PostCSS 플러그인을 추가합니다.

```js filename="postcss.config.mjs"
export default {
  plugins: {
    '@tailwindcss/postcss': {},
  },
}
```

전역 CSS 파일에서 Tailwind를 가져옵니다.

```css filename="app/globals.css"
@import 'tailwindcss';
```

루트 레이아웃에서 CSS 파일을 가져옵니다.

```tsx filename="app/layout.tsx" switcher
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import './globals.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

이제 애플리케이션에서 Tailwind의 유틸리티 클래스를 사용할 수 있습니다.

```tsx filename="app/page.tsx" switcher
export default function Page() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <h1 className="text-4xl font-bold">Welcome to Next.js!</h1>
    </main>
  )
}
```

```jsx filename="app/page.js" switcher
export default function Page() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <h1 className="text-4xl font-bold">Welcome to Next.js!</h1>
    </main>
  )
}
```

> **알아두면 좋은 점:** 매우 오래된 브라우저에 대한 더 광범위한 브라우저 지원이 필요한 경우 [Tailwind CSS v3 설정 지침](../guides/tailwind-v3-css.mdx)을 참조하세요.

## CSS 모듈

CSS 모듈은 고유한 클래스 이름을 생성하여 CSS의 범위를 로컬로 지정합니다. 이를 통해 이름 충돌에 대한 걱정 없이 다른 파일에서 동일한 클래스를 사용할 수 있습니다.

CSS 모듈 사용을 시작하려면 확장명이 `.module.css`인 새 파일을 생성하고 `app` 디렉터리 내의 구성 요소로 가져옵니다.

```css filename="app/blog/blog.module.css"
.blog {
  padding: 24px;
}
```

```tsx filename="app/blog/page.tsx" switcher
import styles from './blog.module.css'

export default function Page() {
  return <main className={styles.blog}></main>
}
```

```jsx filename="app/blog/page.js" switcher
import styles from './blog.module.css'

export default function Layout() {
  return <main className={styles.blog}></main>
}
```

## 전역 CSS

전역 CSS를 사용하여 애플리케이션 전체에 스타일을 적용할 수 있습니다.

Create a `app/global.css` 파일을 생성하고 이를 루트 레이아웃으로 가져와 애플리케이션의 **모든 경로**에 스타일을 적용합니다.

```css filename="app/global.css"
body {
  padding: 20px 20px 60px;
  max-width: 680px;
  margin: 0 auto;
}
```

```tsx filename="app/layout.tsx" switcher
// These styles apply to every route in the application
import './global.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
// These styles apply to every route in the application
import './global.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

> **알아두면 좋은 점:** 전역 스타일은 `app` 디렉터리 내의 모든 레이아웃, 페이지 또는 구성 요소로 가져올 수 있습니다. 그러나 Next.js는 Suspense와 통합하기 위해 React의 내장된 스타일시트 지원을 사용하므로 현재 충돌이 발생할 수 있는 경로 사이를 탐색할 때 스타일시트를 제거하지 않습니다. *진정한* 전역 CSS(예: Tailwind의 기본 스타일)에 전역 스타일을 사용하고, 구성요소 스타일 지정에는 [Tailwind CSS](#tailwind-css), 사용자 정의 범위에는 [CSS 모듈](#css-modules)을 사용하는 것이 좋습니다. CSS 필요할 때.

## 외부 스타일시트

외부 패키지에 의해 게시된 스타일시트는 함께 배치된 구성 요소를 포함하여 `app` 디렉터리의 어느 곳에서나 가져올 수 있습니다.

```tsx filename="app/layout.tsx" switcher
import 'bootstrap/dist/css/bootstrap.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import 'bootstrap/dist/css/bootstrap.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

> **알아두면 좋은 점:** React 19에서는 `<link rel="stylesheet" href="..." />`도 사용할 수 있습니다. 자세한 내용은 [React `link` 문서](https://react.dev/reference/react-dom/components/link)를 참조하세요.

## 순서 및 병합

Next.js는 스타일시트를 자동으로 청크(병합)하여 프로덕션 빌드 중에 CSS를 최적화합니다. **CSS**의 순서는 **코드에서 스타일을 가져오는 순서**에 따라 다릅니다.

예를 들어 `base-button.module.css`은 `page.module.css`보다 먼저 가져오기 때문에 `<BaseButton>`보다 먼저 주문됩니다.`page.module.css`:

```tsx filename="page.tsx" switcher
import { BaseButton } from './base-button'
import styles from './page.module.css'

export default function Page() {
  return <BaseButton className={styles.primary} />
}
```

```jsx filename="page.js" switcher
import { BaseButton } from './base-button'
import styles from './page.module.css'

export default function Page() {
  return <BaseButton className={styles.primary} />
}
```

```tsx filename="base-button.tsx" switcher
import styles from './base-button.module.css'

export function BaseButton() {
  return <button className={styles.primary} />
}
```

```jsx filename="base-button.js" switcher
import styles from './base-button.module.css'

export function BaseButton() {
  return <button className={styles.primary} />
}
```

### 권장 사항

CSS 순서를 예측 가능하게 유지하려면 다음을 수행하세요.

- 단일 JavaScript 또는 TypeScript 항목 파일에 CSS 가져오기를 포함하려고 합니다.
- 애플리케이션 루트에서 전역 스타일과 Tailwind 스타일시트를 가져옵니다.
- **Tailwind CSS**는 유틸리티 클래스로 일반적인 디자인 패턴을 다루므로 대부분의 스타일링 요구 사항에 사용됩니다.
- Tailwind 유틸리티가 충분하지 않은 경우 구성요소별 스타일에 CSS 모듈을 사용하세요.
- CSS 모듈에 대해 일관된 명명 규칙을 사용하십시오. 예를 들어 `<name>.module.css` 대신 `<name>.tsx`을 사용합니다.
- 중복 가져오기를 피하기 위해 공유 스타일을 공유 구성요소로 추출합니다.
- ESLint의 [`sort-imports`](https://eslint.org/docs/latest/rules/sort-imports)과 같은 가져오기를 자동 정렬하는 린터 또는 포맷터를 끄십시오.
- You can use the [`cssChunking`](../api-reference/config/next-config-js/cssChunking.mdx) 옵션을 사용하여 CSS가 청크되는 방식을 제어할 수 있습니다.`next.config.js` to control how CSS is chunked.

## 개발 vs 생산

- 개발 중(`next dev`), CSS 업데이트는 [빠른 새로 고침](../../architecture/fast-refresh.mdx)을 통해 즉시 적용됩니다.
- 프로덕션(`next build`)에서는 모든 CSS 파일이 자동으로 **많은 축소 및 코드 분할** `.css` 파일로 연결되어 경로에 대해 최소한의 CSS가 로드되도록 합니다.
- CSS는 프로덕션에서 JavaScript가 비활성화된 상태로 계속 로드되지만 빠른 새로 고침을 위해 개발하려면 JavaScript가 필요합니다.
- CSS 순서는 개발 중에 다르게 동작할 수 있으므로 항상 빌드(`next build`)를 확인하여 최종 CSS 순서를 확인하세요.
