Next.js는 구성이 필요 없는 **최신 브라우저**를 지원합니다.

- Chrome 111+
- Edge 111+
- Firefox 111+
- Safari 16.4+

## 브라우저 목록

특정 브라우저나 기능을 타겟팅하려는 경우 Next.js는 `package.json` 파일에서 [브라우저 목록](https://browsersl.ist) 구성을 지원합니다. Next.js는 기본적으로 다음 브라우저 목록 구성을 사용합니다.

```json filename="package.json"
{
  "browserslist": ["chrome 111", "edge 111", "firefox 111", "safari 16.4"]
}
```

## 폴리필

다음을 포함하여 [널리 사용되는 폴리필](https://github.com/vercel/next.js/blob/canary/packages/next-polyfill-nomodule/src/index.js)을 삽입합니다.

- [**fetch()**](https://developer.mozilla.org/docs/Web/API/Fetch_API) — 교체: `whatwg-fetch` 및 `unfetch`.
- [**URL**](https://developer.mozilla.org/docs/Web/API/URL) — 교체: [`url` 패키지(Node.js API)](https://nodejs.org/api/url.html).
- [**Object.sign()**](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Object/assign) — 교체: `object-assign`, `object.assign` 및 `core-js/object/assign`.

종속성 중 하나에 이러한 폴리필이 포함되어 있으면 중복을 피하기 위해 프로덕션 빌드에서 자동으로 제거됩니다.

또한 번들 크기를 줄이기 위해 Next.js는 이러한 폴리필이 필요한 브라우저에 대해서만 이러한 폴리필을 로드합니다. 전 세계적으로 웹 트래픽의 대부분은 이러한 폴리필을 다운로드하지 않습니다.

### 사용자 정의 폴리필

자신의 코드나 외부 npm 종속성이 대상 브라우저(예: IE 11)에서 지원하지 않는 기능을 요구하는 경우 폴리필을 직접 추가해야 합니다.

#### 인앱 라우터

폴리필을 포함하려면 [`instrumentation-client.js` 파일](../app/api-reference/file-conventions/instrumentation-client.mdx)로 가져올 수 있습니다.

```ts filename="instrumentation-client.ts"
import './polyfills'
```

#### 인 페이지 라우터

이 경우 [사용자 정의 `<App>`](https://nextjs.org/docs/pages/building-your-application/routing/custom-app) 또는 개별 구성 요소에 필요한 **특정 폴리필**에 대한 최상위 가져오기를 추가해야 합니다.

```tsx filename="pages/_app.tsx" switcher
import './polyfills'

import type { AppProps } from 'next/app'

export default function MyApp({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
```

```jsx filename="pages/_app.jsx" switcher
import './polyfills'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

#### 조건부로 폴리필 로드

가장 좋은 접근 방식은 지원되지 않는 기능을 특정 UI 섹션으로 격리하고 필요한 경우 폴리필을 조건부로 로드하는 것입니다.

```ts filename="hooks/analytics.ts" switcher
import { useCallback } from 'react'

export const useAnalytics = () => {
  const tracker = useCallback(async (data: unknown) => {
    if (!('structuredClone' in globalThis)) {
      import('polyfills/structured-clone').then((mod) => {
        globalThis.structuredClone = mod.default
      })
    }

    /* Do some work that uses structured clone */
  }, [])

  return tracker
}
```

```js filename="hooks/analytics.js" switcher
import { useCallback } from 'react'

export const useAnalytics = () => {
  const tracker = useCallback(async (data) => {
    if (!('structuredClone' in globalThis)) {
      import('polyfills/structured-clone').then((mod) => {
        globalThis.structuredClone = mod.default
      })
    }

    /* Do some work that uses structured clone */
  }, [])

  return tracker
}
```

## JavaScript 언어 기능

Next.js를(를) 사용하면 최신 JavaScript 기능을 바로 사용할 수 있습니다. [ES6 기능](https://github.com/lukehoban/es6features) 외에도 Next.js는 다음을 지원합니다.

- [비동기/대기](https://github.com/tc39/ecmascript-asyncawait)(ES2017)
- [객체 나머지/확산 속성](https://github.com/tc39/proposal-object-rest-spread) (ES2018)
- [동적 `import()`](https://github.com/tc39/proposal-dynamic-import)(ES2020)
- [선택적 체인](https://github.com/tc39/proposal-optional-chaining)(ES2020)
- [무효 병합](https://github.com/tc39/proposal-nullish-coalescing)(ES2020)
- [클래스 필드](https://github.com/tc39/proposal-class-fields) 및 [정적 속성](https://github.com/tc39/proposal-static-class-features)(ES2022)
- 그리고 더!
